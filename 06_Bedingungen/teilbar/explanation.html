Erklärung

Ob eine Zahl ganzzahlig durch eine andere teilbar ist, prüfen Sie mit dem Modulo-Operator %: Er liefert den Rest der ganzzahligen Division. Ist der Rest 0, geht die Division auf, z.B. 210 % 3 == 0, aber 49 % 3 == 1.

  • Drei einzelne if-Anweisungen: Eine Zahl kann durch mehrere der Zahlen teilbar sein (210 ist durch alle drei teilbar). Deshalb wird jede Bedingung für sich geprüft. Mit if ... else if ... würde nach der ersten zutreffenden Bedingung abgebrochen, und für 210 erschiene nur gerade.
  • Der Fall Unbekannt: Er tritt nur ein, wenn keine der drei Bedingungen zutrifft, also wenn x durch 2 und durch 3 und durch 5 nicht teilbar ist: x % 2 != 0 && x % 3 != 0 && x % 5 != 0. Ein einfaches else am Ende reicht nicht, denn es gehört nur zur letzten if-Anweisung. Für 4 würde sonst gerade und zusätzlich Unbekannt ausgegeben.

Da x bei jedem Ausführen zufällig gewählt wird, sollten Sie das Programm mehrmals starten, um verschiedene Fälle zu testen.

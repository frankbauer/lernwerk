Erklärung

Diese Aufgabe zeigt, wie mithilfe von if und else Fallunterscheidungen vorgenommen werden können. Sofern Sie eine ausführliche Erklärung zum bereits vorgegebenen Code-Teil wünschen, schauen Sie sich die Aufgabe Tankstellensuche im Kapitel Methodenaufrufe an.

  • Fallunterscheidung: Ist eine Tankstelle in Reichweite?:

    Die Methode getFillingStation der Klasse Car prüft, ob innerhalb der übergebenen Reichweite eine Tankstelle vorhanden ist. Dabei wird die Tankstelle bevorzugt, bei der mit Bezug auf die übergebene Richtung der kleinste Umweg nötig ist. Wird eine Tankstelle innerhalb der Reichweite gefunden, wird diese als String zurückgegeben, andernfalls wird null zurückgegeben. Der Rückgabewert wird in der Variablen fillingStation gespeichert. Entsprechend kann diese Variable im Anschluss für die Bedingung verwendet werden, um zu bestimmen, welcher Codeteil ausgeführt werden soll - der, der ablaufen soll, wenn eine Tankstelle in Reichweite gefunden wurde oder der, wenn keine gefunden wurde. 

    String fillingStation = Car.getFillingStation(direction, range);

    In der Beispiellösung wurde sich dazu entschieden, mittels eines if-Statements zu überprüfen, ob fillingStation ungleich (!=) null ist. Das ist der Fall, wenn eine Tankstelle in Reichweite gefunden wurde, da dann der String mit dem Tankstellennamen in fillingStation steht. Falls die Bedingung zutrifft, ist das Ergebnis der Bedingung true und der Code in den geschweiften Klammern {...} nach dem if-Statement wird ausgeführt. Der Abschnitt else{...} wird nicht beachtet. Ist die Bedingung nicht erfüllt, das heißt, fillingStation ist gleich null, so wurde keine Tankstelle in Reichweite gefunden. In diesem Fall wird der Teil innerhalb der geschweiften Klammern nach der if-Bedingung übersprungen und stattdessen der Abschnitt in den geschweiften Klammern {...} nach else ausgeführt.

    if(fillingStation != null){
    ...
} else {
    ...
}

    Alternativ könnte auch geprüft werden ob, fillingStation gleich (==) null ist und der Inhalt innerhalb der geschweiften Klammern von if- und else-Statement getauscht werden.

    if(fillingStation == null){
    ... //Inhalt hier der von else {...} in Beispiellösung
} else {
    ... //Inhalt hier der von if {...} in Beispiellösung
}
  • Fall: Tankstelle in Reichweite:

    Sofern die Tankstelle in Reichweite liegt, wird mithilfe der Methode startNavigation der Klasse Car die Navigation zur Tankstelle gestartet.

    Car.startNavigation(fillingStation);
  • Fall: Tankstelle nicht innerhalb der aktuellen Reichweite:
    • Ausgabe "bei aktuellem Verbrauch nicht erreichbar":

      In diesem Fall hat getFillingStation null zurückgegeben und wir befinden uns nun im else-Block. Zunächst wird mittels System.out.prinln ausgegeben, dass bei dem aktuellen Verbrauch keine erreichbare Tankstelle gefunden wurde.

      System.out.println("Keine bei aktuellem Verbrauch erreichbare Tankstelle gefunden.");
    • Suche nach der nächsten Tankstelle:

      Im Anschluss wird mithilfe der Methode getNearestFillingStation nach der am wenigsten weit entfernten Tankstelle gesucht. Das Ergebnis der Suche wird der Variablen fillingStation zugewiesen und überschreibt damit den bisherigen Inhalt (null). 

      fillingStation = Car.getNearestFillingStation();
    • Entfernung zur nächsten Tankstelle:

      Danach wird die Entfernung zu eben dieser Tankstelle bestimmt, indem die Methode getDistance mit fillingStation als Parameter aufgerufen wird. Diese Methode gibt einen float-Wert zurück, der in der Variablen distance abgelegt wird. Mit System.out.println werden die Ergebnisse als Textnachricht ausgegeben. 

      float distance = Car.getDistance(fillingStation);
System.out.println("Naechste Tankstelle in " + distance + " km: " + fillingStation);
    • Bestimmung des maximal erlaubten Verbrauchs:

      Aus dem Füllstand und der Entfernung kann dann der Verbrauch berechnet werden, der maximal erlaubt ist, um die nächste Tankstelle zu erreichen. Die Berechnungsformel dazu ist in der Angabe gegeben. Der Füllstand wurde im vorgegebenen Code-Teil in der Variablen fillLvel gespeichert, während die Entfernung in der Variablen distance hinterlegt ist. Das Ergebnis der Berechnung wird in der Variablen maxConsumption abgelegt. Nachdem sowohl fillLevel als auch distance float-Werte sind, wurde auch maxConsumption als float-Variable deklariert. 

      float maxConsumption = fillLevel/distance*100;
    • Fallunterscheidung: Verbrauchsreduktion ausreichend möglich?:

      Zum Schluss muss anhand des berechneten maximal erlaubten Verbrauchs noch eine Fallunterscheidung vorgenommen werden. Der Verbrauch kann minimal bis zu einem Wert von 3,5l/100km reduziert werden, eine weitere Reduktion ist nicht möglich. Deshalb wird in einer if-Bedingung geprüft, ob maxConsumption größer gleich 3,5 ist. 

      if (maxConsumption >= 3.5f){...}

      Falls ja, ist es möglich, den Verbrauch ausreichend zu reduzieren, um die nächste Tankstelle zu erreichen. Es kann also ausgegeben werden, auf welchen Wert der Verbrauch reduziert werden muss. Der derzeitige Verbrauch steht in der Variablen consumption, der Verbrauch, auf den reduziert werden muss, in der Variablen maxConsumption. Beide werden mittels "+" in das System.out.println-Statement aufgenommen. Zusätzlich kann die Navigation zur mit getNearestFillingStation gefundenen Tankstelle fillingStation gestartet werden. Dazu wird auch hier die Methode startNavigation verwendet. 

      System.out.println("Verbrauch muss von " + consumption + " l/100km auf " + maxConsumption + " l/100km gesenkt werden.");
Car.startNavigation(fillingStation);

      Falls der Verbrauch unter 3,5l/100km reduziert werden müsste, besteht keine Hoffnung mehr, dass noch eine Tankstelle erreicht werden kann. Deshalb wird im else-Teil keine Navigation gestartet. Stattdessen wird ausgegeben, dass auch mit Verbrauchsreduktion keine Tankstelle erreicht werden kann und dass angehalten und Hilfe gerufen werden sollte. Dies erfolgt auch hier wieder mittels System.out.println. 

      System.out.println("Auch bei Verbrauchsreduktion kann die Tankstelle nicht erreicht werden. "); 
System.out.println("Halten Sie an und rufen Sie Hilfe.");

Aufgabe

In dieser Aufgabe programmieren Sie einen Teil einer vereinfachten Version der Enigma zur Verschlüsselung von Text.

Dazu implementieren Sie die Klasse Walze. Eine Walze ersetzt einen eingehenden Buchstaben durch einen anderen. Diese Abbildung ist eindeutig, d.h. jeder Buchstabe wird auf genau einen anderen abgebildet.

Die Abbildung wird durch ein Feld von Zahlen dargestellt (Mapping-Array). Die Buchstaben a bis z werden dafür als Zahlen von 0 bis 25 dargestellt (siehe getIndexFromChar und getCharFromIndex im Reiter Helper). Gilt für das Mapping-Array M[0] = 6, dann wird der Buchstabe a (0) auf g (6) abgebildet.

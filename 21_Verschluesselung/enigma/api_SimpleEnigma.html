class SimpleEnigma

Eine vereinfachte Enigma, in die bis zu drei Walzen eingesetzt werden können.

Konstruktor:

  • SimpleEnigma()
Erstellt eine Enigma ohne Walzen.

Methoden:

  • void addComponent(Walze w)
Setzt eine Walze in die Enigma ein. Es können maximal 3 Walzen eingesetzt werden,
weitere Aufrufe haben keine Wirkung.
  • String encryptSentence(String s)
Verschlüsselt einen Satz Zeichen für Zeichen mit allen eingesetzten Walzen
(in der Reihenfolge des Einsetzens). Leerzeichen bleiben erhalten.
  • String decryptSentence(String s)
Entschlüsselt einen Satz wieder (Walzen in umgekehrter Reihenfolge), solange zwischen
Ver- und Entschlüsseln keine neue Walze eingesetzt wurde.

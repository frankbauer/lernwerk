Aufgabe

Gegeben ist der Datentyp Vec2D, der einen 2D-Vektor repräsentiert und zwei double-Werte x und y speichert. Ergänzen Sie die Klasse um einige Rechenmöglichkeiten.

  1. Schreiben Sie eine öffentliche Instanzmethode length, die die Länge des Vektors zurückgibt. Nutzen Sie dazu eine geeignete Methode aus der Math-Klasse der Java-API. Die Länge berechnet sich wie folgt: length= x2+y2
  2. Schreiben Sie eine öffentliche Methode add, die einen Vec2D übergeben bekommt und ihn komponentenweise auf die Instanz addiert, auf der die Methode aufgerufen wird.
  3. Schreiben Sie eine private Klassenmethode normalizeAll, die ein Feld von Vec2D übergeben bekommt und jeden darin enthaltenen Vektor normalisiert, d.h. komponentenweise durch die Länge des Vektors teilt.
  4. Testen Sie Ihren Code mit Hilfe einer main-Methode.

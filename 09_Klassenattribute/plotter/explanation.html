Erklärung

private static double f(double x, double k, double t) {
    Plotter.callCount++;
    return Plotter.A * Math.sqrt(Math.abs(x - t * k * k)) + t * Math.abs(k + Plotter.B);
}
  • Deklaration: private macht die Methode nur innerhalb der Klasse Plotter sichtbar, static macht sie zur Klassenmethode. Deshalb kann main sie ohne Objekt aufrufen.
  • Formel: Die Wurzel berechnet Math.sqrt, den Betrag Math.abs. Für k2 reicht k * k. Anders als in der mathematischen Schreibweise muss jede Multiplikation mit * ausgeschrieben werden.
  • Klassenattribute: A, B und callCount gehören zur Klasse, nicht zu einem Objekt. Man greift mit Plotter.A auf sie zu. Innerhalb der Klasse genügt auch A.
  • Aufrufzähler: Weil callCount ein Klassenattribut ist, behält es seinen Wert zwischen den Aufrufen. Jeder Aufruf von f erhöht es um 1. Die Schleife in main läuft von -1 bis 1.75 in Schritten von 0.25. Am Ende steht daher Call Counter: 12 in der Ausgabe.

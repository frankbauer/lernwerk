Erklärung

Jedes Java-Programm besteht aus mindestens einer Klasse. Der Name der öffentlichen Klasse muss dabei mit dem Dateinamen übereinstimmen.

  • public class Nachricht { Definiert die Klasse Nachricht. Da die Datei Nachricht.java heißt, muss auch die Klasse so heißen.
  • public static void main(String[] args) { Definiert die main-Methode. Sie ist der Startpunkt des Programms: Beim Ausführen beginnt Java hier mit der ersten Anweisung.
  • System.out.println("Max Mustermann"); Gibt den Text zwischen den Anführungszeichen auf der Konsole aus und beginnt danach eine neue Zeile. Setzen Sie hier natürlich Ihren eigenen Namen ein.
  • Die beiden schließenden Klammern } beenden zuerst die main-Methode und dann die Klasse.

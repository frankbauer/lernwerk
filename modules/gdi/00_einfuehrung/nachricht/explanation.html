Erklärung

Jedes Java-Programm besteht aus mindestens einer Klasse. Der Name der öffentlichen Klasse muss dabei mit dem Dateinamen übereinstimmen.

  • public class Nachricht { Definiert die Klasse Nachricht. Da die Datei Nachricht.java heißt, muss auch die Klasse so exakt heißen (groß- und kleinschriebung ist in Java wichtig!).
  • public static void main(String[] args) { Definiert die main-Methode. Sie ist der Startpunkt des Programms: Nach dem Ausführen beginnt Java mit der ersten Anweisung in dieser Methode.
  • System.out.println("Kim Musterdann"); Die erste Anweisung in der main-Methode. Gibt den Text zwischen den Anführungszeichen auf der Konsole aus und beginnt danach eine neue Zeile (wegen println statt print). Hier sollte natürlich Ihr eigener Name stehen.
  • Die erste schließenden Klammern } beenden die main-Methode, die zweite dann die Klasse. Geschweifte Klammern treten in Java immer paarweise auf.

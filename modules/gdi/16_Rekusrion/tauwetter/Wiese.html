Beschreibung

Die Klasse Wiese beschreibt eine rechteckige Wiese aus Zeilen und Spalten. Auf jedem Feld steht entweder ein Schneemann, ein Baum oder ein Felsen, oder das Feld ist frei. Zeile 0 und Spalte 0 liegen in der hinteren Ecke der Darstellung.

Konstruktoren

  • public Wiese(String[] args)
    Erstellt die Wiese aus den übergebenen Programmargumenten.

Methoden

  • public boolean istSchneemann(int zeile, int spalte)
    Gibt true zurück, wenn an der Position ein Schneemann steht, der noch nicht geschmolzen ist. Bei ungültigen Positionen wird eine Fehlermeldung ausgegeben und false zurückgegeben.
  • public void schmelzen(int zeile, int spalte)
    Lässt den Schneemann an der Position schmelzen. Steht dort kein Schneemann, wird eine Fehlermeldung ausgegeben.
  • public void sonnenstrahl(int zeile, int spalte)
    Zeigt in der Darstellung einen Sonnenstrahl auf der Position an. An der Wiese ändert sich dadurch nichts.
  • public int anzahlSchneemaenner()
    Gibt zurück, wie viele Schneemänner noch stehen.
  • public void setDelay(int delayInMs)
    Setzt die Verzögerung zwischen zwei Animationsschritten in Millisekunden (Standard: 60).

Attribute

  • public final int zeilen
    Die Anzahl der Zeilen der Wiese.
  • public final int spalten
    Die Anzahl der Spalten der Wiese.

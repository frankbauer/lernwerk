Aufgabe

Gegeben ist eine lineare Endrekursion zur Umrechnung einer gegebenen binären Zahl (als Zeichenkette, z.B. "1010") in eine positive Dezimalzahl.

Erstellen Sie eine iterative Variante, die durch den Aufruf der statischen Methode public static int binStringToDecIter(String binaryNumber) ausgeführt wird. Beide Varianten sollen dieselben Ergebnisse liefern:

Endrekursion:
1010 -> 10
11010010 -> 210

Iterativ:
1010 -> 10
11010010 -> 210

Aufgabe

Ordnen Sie die gegebenen Codezeilen so an, dass die Methode dreheUm den übergebenen Text umdreht und diesen zurückgibt. Ziehen Sie die Zeilen dazu mit der Maus (oder dem Finger) an die richtige Stelle oder verschieben Sie sie mit den Pfeilen.

Beispiel: Wird der Text "Beispiel" übergeben, so soll die Methode "leipsieB" zurückgeben.

Hinweis: Die String-Methode substring(int start, int end) aus der Java-API gibt den Teil-String zwischen Index start (inklusive) und end (exklusive) zurück.

Für diese Aufgabe gibt es mehrere richtige Lösungen.

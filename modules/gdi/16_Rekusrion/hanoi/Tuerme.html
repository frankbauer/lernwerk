Beschreibung

Die Klasse Tuerme verwaltet die drei Stäbe 0, 1 und 2 der Türme von Hanoi. Zu Beginn liegen alle Scheiben auf Stab 0. Die Scheiben sind nach ihrer Größe von 1 (die kleinste) bis scheiben (die größte) nummeriert.

Konstruktoren

  • public Tuerme(int scheiben)
    Erstellt einen Turm aus scheiben Scheiben (1 bis 10) auf Stab 0.

Methoden

  • public void bewege(int von, int nach)
    Legt die oberste Scheibe von Stab von auf Stab nach und gibt den Zug aus. Ungültige Züge (leerer Stab, größere auf kleinere Scheibe) werden nicht ausgeführt, sondern erzeugen eine Fehlermeldung.
  • public int anzahlZuege()
    Gibt die Anzahl der gültigen Züge zurück.
  • public boolean istFertig()
    Gibt true zurück, wenn alle Scheiben auf Stab 2 liegen.
  • public int anzahlScheiben(int stab)
    Gibt zurück, wie viele Scheiben auf dem Stab liegen.
  • public int obersteScheibe(int stab)
    Gibt die Nummer der obersten Scheibe des Stabs zurück (0, wenn er leer ist).
  • public void setDelay(int delayInMs)
    Setzt die Dauer eines Zugs in der Darstellung in Millisekunden (Standard: 500). Jeder Zug wird sofort gezeichnet, das Programm wartet so lange.

Attribute

  • public final int scheiben
    Die Anzahl der Scheiben.

Aufgabe

Bei den Türmen von Hanoi liegen Scheiben unterschiedlicher Größe als Turm auf Stab 0, die größte unten. Der ganze Turm soll auf Stab 2 umgesetzt werden. Dabei gelten zwei Regeln:

  • Es darf immer nur die oberste Scheibe eines Stabs bewegt werden.
  • Eine Scheibe darf nie auf einer kleineren Scheibe liegen.

Implementieren Sie die Methode hanoi(Tuerme tuerme, int n, int von, int nach, int hilf) rekursiv. Sie soll die obersten n Scheiben vom Stab von auf den Stab nach bringen und darf den Stab hilf als Zwischenablage verwenden. Die Stäbe sind von 0 bis 2 nummeriert. Eine Scheibe bewegen Sie mit tuerme.bewege(von, nach).

Bei richtiger Lösung gibt das Programm Folgendes aus:

Scheibe 1: 0 -> 1
Scheibe 2: 0 -> 2
Scheibe 1: 1 -> 2
Scheibe 3: 0 -> 1
Scheibe 1: 2 -> 0
Scheibe 2: 2 -> 1
Scheibe 1: 0 -> 1
Scheibe 4: 0 -> 2
Scheibe 1: 1 -> 2
Scheibe 2: 1 -> 0
Scheibe 1: 2 -> 0
Scheibe 3: 1 -> 2
Scheibe 1: 0 -> 1
Scheibe 2: 0 -> 2
Scheibe 1: 1 -> 2
Zuege: 15
Alle Scheiben auf Stab 2: true

Hinweis: Stellen Sie sich vor, Sie könnten die oberen n - 1 Scheiben schon (rekursiv) als Ganzes umsetzen. Wohin müssen sie, damit die größte Scheibe frei wird? Und was passiert danach?

Ergänzen Sie die gegebene Methode istPalindrom um folgende Funktionalität:

Die Methode soll rekursiv überprüfen, ob das übergebene (kleingeschriebene) Wort ein Palindrom ist. Ein Wort ist genau dann ein Palindrom, wenn es rückwärts gelesen das gleiche Wort ergibt wie vorwärts (z.B. reittier). Das Programm soll folgende Ausgabe erzeugen:

regallager ist ein Palindrom: true
rentner ist ein Palindrom: true
kaninchen ist ein Palindrom: false

Nutzen Sie dazu die Methode substring aus der String-API:

public String substring(int beginIndex, int endIndex)

Gibt einen neuen String zurück, der ein Teil dieses Strings ist. Er beginnt beim Index beginIndex und reicht bis zum Zeichen mit dem Index endIndex - 1. Die Länge des Teil-Strings ist also endIndex - beginIndex.

Beispiele:

"hamburger".substring(4, 8)   // ergibt "urge"
"smiles".substring(1, 5)      // ergibt "mile"

Parameter: beginIndex – Startindex (inklusive), endIndex – Endindex (exklusive)

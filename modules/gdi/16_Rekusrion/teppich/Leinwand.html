Beschreibung

Die Klasse Leinwand beschreibt eine quadratische Leinwand aus Feldern, die gefüllt werden können. Zeile 0 ist oben, Spalte 0 ist links.

Konstruktoren

  • public Leinwand(int groesse)
    Erstellt eine leere Leinwand mit groesse Zeilen und Spalten.

Methoden

  • public void fuellen(int zeile, int spalte)
    Füllt das Feld an der Position. Ist die Position ungültig oder das Feld schon gefüllt, wird eine Fehlermeldung ausgegeben.
  • public boolean istGefuellt(int zeile, int spalte)
    Gibt zurück, ob das Feld gefüllt ist.
  • public int anzahlGefuellt()
    Gibt zurück, wie viele Felder gefüllt sind.
  • public void setDelay(int delayInMs)
    Setzt die Zeit zwischen zwei gefüllten Feldern in der Darstellung in Millisekunden (Standard: 8). Jedes Feld wird sofort gezeichnet, das Programm wartet so lange.

Attribute

  • public final int zeilen
    Die Anzahl der Zeilen.
  • public final int spalten
    Die Anzahl der Spalten.

Aufgabe

Gegeben ist eine lineare Kopfrekursion zur Umrechnung einer gegebenen binären Zahl (als Zeichenkette, z.B. "1010") in eine positive Dezimalzahl.

Erstellen Sie eine endrekursive Variante, die durch den Aufruf der statischen Methode public static int binStringToDecTail(String binaryNumber) ausgeführt wird. Beide Varianten sollen dieselben Ergebnisse liefern:

Kopfrekursion:
1010 -> 10
11010010 -> 210

Endrekursion:
1010 -> 10
11010010 -> 210

Hinweis: Eine endrekursive Methode braucht meist einen zusätzlichen Parameter für das Zwischenergebnis. Dafür dürfen Sie eine weitere Hilfsmethode schreiben.

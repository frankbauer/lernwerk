Aufgabe

In dieser Aufgabe schreiben Sie eine Klasse, die ein Feld kapselt, und lernen dabei die wichtigsten Grundbegriffe von Bibliotheken für maschinelles Lernen wie TensorFlow kennen: Tensor, Form, reshape und elementweise Rechenoperationen.

Ein Tensor ist ein Objekt, das beliebig viele Zahlen speichert, die als Tabelle mit mehreren Dimensionen gelesen werden. Intern liegen alle Werte in einem einfachen Feld double[] daten, zeilenweise hintereinander. Ein zweites Feld int[] form gibt an, wie diese Werte zu lesen sind:

Tabelle            daten                              form
  0   51  102      {0, 51, 102, 153, 204, 255}        {2, 3}   (2 Zeilen, 3 Spalten)
153  204  255

Im Playground unten ist ein kleines neuronales Netz eingebaut, das gezeichnete Formen erkennt (waagrechte und senkrechte Linie, Kreuz, Plus, Kreis). In TensorFlow.js würde man das gezeichnete Bild so vorbereiten:

tf.tensor2d(bild).reshape([1, 120]).div(255)

Schreiben Sie die Klasse Tensor so, dass dieselbe Zeile auch in Java funktioniert. Die Klasse Erkennung testet Ihre Klasse zuerst an einem kleinen Beispiel. Erst wenn alle Tests bestanden sind, erhält das Netz Ihren Tensor und erkennt die gezeichnete Form.

Ändern Sie div so, dass die Werte direkt in this.daten geteilt werden und this zurückgegeben wird. Welcher Test schlägt fehl? Der Test „Daten des ursprünglichen Tensors“: Der Tensor t enthält nach t.div(255) plötzlich die Werte 0.0 bis 1.0. Wer noch eine Referenz auf t (oder auf einen Tensor mit demselben Feld) hat, sieht die veränderten Werte.
Ändern Sie in Erkennung die Form zu {120, 1}. Was passiert? reshape funktioniert, denn 120 Werte passen auch in 120 x 1. Die Werte im Feld sind dieselben, und das Netz erkennt die Form trotzdem. Die Ausgabe weist aber darauf hin, dass das Netz die Form {1, 120} erwartet. In TensorFlow würde predict hier mit einer Fehlermeldung abbrechen.
Ergänzen Sie eine Methode Tensor mul(double wert) und eine Methode Tensor sub(double wert). Bereiten Sie das Bild damit so vor, dass die Werte zwischen -1.0 und 1.0 liegen. Mit .div(255).mul(2).sub(1) wird aus 0 der Wert -1.0 und aus 255 der Wert 1.0. Das Netz wurde aber mit Werten von 0.0 bis 1.0 trainiert und erkennt die Formen deshalb schlechter.
Schreiben Sie eine Methode int anzahl(), die die Anzahl der Werte allein aus form berechnet, und verwenden Sie sie in reshape. 
public int anzahl() {
    int produkt = 1;
    for (int i = 0; i < this.form.length; i++) {
        produkt = produkt * this.form[i];
    }
    return produkt;
}

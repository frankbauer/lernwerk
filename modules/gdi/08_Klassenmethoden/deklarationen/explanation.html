Erklärung

Eine Methodendeklaration besteht aus Modifikatoren, Rückgabetyp, Methodenname, Parameterliste und Methodenrumpf. Jeder dieser Teile muss den Regeln von Java entsprechen.

Gültig sind:

  • createTree(String name): Alle Bestandteile sind vorhanden. void bedeutet, dass nichts zurückgegeben wird.
  • sum(int a, double y): Die Parameter dürfen verschiedene Typen haben. a + y ergibt einen double-Wert und passt damit zum Rückgabetyp. Auch private ist ein erlaubter Modifikator.
  • findMin(Robot[] robots): Ein Parameter darf auch ein Array oder eine eigene Klasse als Typ haben.

Ungültig sind:

  • dif: Nach final int a = 13 fehlt das Semikolon. Außerdem gibt es bereits einen Parameter a. Eine lokale Variable darf nicht denselben Namen wie ein Parameter haben.
  • double(): double ist ein Schlüsselwort und darf nicht als Methodenname verwendet werden.
  • findOld(Tree[]) und div(double, double): Jeder Parameter braucht einen Typ und einen Namen. Nur über den Namen kann im Rumpf auf den Wert zugegriffen werden.
  • hasID(Player p, void id): void steht für „kein Wert“ und ist nur als Rückgabetyp erlaubt, nicht als Typ eines Parameters.
  • mul: Der Rückgabetyp ist int, der Rumpf enthält aber keine return-Anweisung. System.out.println gibt den Wert nur aus, zurückgegeben wird er dadurch nicht.

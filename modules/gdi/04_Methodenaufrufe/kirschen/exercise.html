Aufgabe

In dieser Aufgabe steuern Sie die schwebende Welt ausschließlich mit Klassenmethoden der Klasse FloatingWorld (eine Beschreibung finden Sie im Reiter FloatingWorld).

Teil 1: Die Welt bewegen

Das Programm zeigt die Welt an und fügt einen Spieler hinzu. Der Spieler steht aber nicht bei der Kirsche. Ergänzen Sie das Programm so, dass der Spieler die Kirsche aufsammelt, ohne den Spieler selbst zu bewegen. Suchen Sie dazu in der Klassendokumentation eine passende Methode.

Teil 2: Spieler über ihre Nummer auswählen

Mit mehreren Spielern müssen Sie angeben, welcher Spieler sich bewegen soll. Dazu erhält jeder Spieler eine Nummer (beginnend bei 0). Verwenden Sie die folgenden Klassenmethoden:

  • static void show() Zeigt die Welt an.
  • static void addPlayer() Fügt einen Spieler hinzu.
  • static void movePlayerLeft(int playerID) Bewegt den Spieler mit der Nummer playerID nach links.
  • static void movePlayerRight(int playerID) Bewegt den Spieler mit der Nummer playerID nach rechts.
  • static void removePlayer(int playerID) Löscht den Spieler mit der Nummer playerID.

Gehen Sie wie folgt vor:

  1. Fügen Sie zwei neue Spieler hinzu.
  2. Bewegen Sie den pinken Spieler nach rechts.
  3. Bewegen Sie den roten Spieler nach rechts (dieser sollte nun die Kirsche aufnehmen).
  4. Löschen Sie den pinken Spieler.
  5. Bewegen Sie den roten Spieler nach links.

Auf dem Spielfeld sollte am Ende des Durchlaufs der rote Spieler an seiner Ausgangsposition (weiß gestrichelter Umriss) mit der Kirsche über seinem Kopf stehen. In der Ausgabe unter dem Spielfeld sehen Sie, ob Ihre Befehlsfolge richtig ist.

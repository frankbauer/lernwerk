Erklärung

Alle Methoden sind Klassenmethoden (static). Sie werden daher über den Klassennamen aufgerufen, z.B. FloatingWorld.addPlayer(), ohne dass vorher ein Objekt erzeugt werden muss.

  • Spieler hinzufügen: Zweimal FloatingWorld.addPlayer();. Die Spieler werden in der Reihenfolge ihres Hinzufügens nummeriert, beginnend bei 0: Der zuerst hinzugefügte pinke Spieler hat die ID 0, der rote die ID 1.
  • Nach rechts bewegen: FloatingWorld.movePlayerRight(0); bewegt den pinken, FloatingWorld.movePlayerRight(1); den roten Spieler. Die ID wird der Methode als Parameter übergeben. Der rote Spieler landet dabei genau auf der Kirsche und nimmt sie auf.
  • Pinken Spieler löschen: FloatingWorld.removePlayer(0);
  • Roten Spieler nach links bewegen: Hier liegt die Falle. Nach dem Löschen gibt es nur noch einen Spieler, und alle nachfolgenden Spieler rücken um eine Position nach vorne. Der rote Spieler hat jetzt die ID 0, daher FloatingWorld.movePlayerLeft(0);. Mit movePlayerLeft(1) erscheint in der Ausgabe die Meldung, dass es keinen Spieler mit der ID 1 gibt.

Erklärung

Alle Methoden sind Klassenmethoden (static). Sie werden daher über den Klassennamen aufgerufen, z.B. FloatingWorld.addPlayer(), ohne dass vorher ein Objekt erzeugt werden muss.

  • Spieler hinzufügen: Zweimal FloatingWorld.addPlayer() aufrufen nachdem die Welt angezeigt wurde. Die Spieler werden in der einfügereihenfolge, beginnend bei 0, nummeriert. Der erste Spieler ist pink und hat die ID 0, der zweite rote mit der ID 1.
  • Spieler bewegen: FloatingWorld.movePlayerRight(1) bewegt den roten, FloatingWorld.movePlayerLeft(0) den pinken Spieler. Die numerische ID wird der Methode als Parameter in den rundenen Klammern übergeben.
  • Welt verschieben: FloatingWorld.moveLeft() verschiebt die gesamte Welt (Insel, Baum, Stein und Kirsche) nach links. Die Spieler werden nicht mitbewegt, die Kirsche kommt also zum roten Spieler. Die Methode hat keine Parameter, die leeren Klammern sind trotzdem nötig.
  • Pinken Spieler löschen: FloatingWorld.removePlayer(0). Pink war der zuerst hinzugefügte Spieler und hat deswegen die ID 0.
  • Roten Spieler nach links bewegen: Hier liegt die Falle. Nach dem Löschen gibt es nur noch einen Spieler, und alle nachfolgenden Spieler rücken um eine Position nach vorne. In dieser Welt hat der älteste Spieler immer die ID 0. Daher ist der einzig verbleibende Spieler über die ID 0 erreichbar. Die Methode FloatingWorld.movePlayerLeft wird also mit der ID 0 aufgerufen. movePlayerLeft(1) würde nun zu einer Fehlermeldung führen, weil es keinen Spieler mehr mit der ID 1 gibt.

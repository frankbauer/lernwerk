Erklärung

  • Aufruf von FloatingWorld.show():

    Diese Methode wird aufgerufen, um die FloatingWorld anzuzeigen. Sie ist statisch (siehe API-Seite von FloatingWorld), gehört zur Klasse FloatingWorld und wird somit über den Klassennamen vor dem Punkt aufgerufen.

  • Aufruf von FloatingWorld.addPlayer():

    Diese Methode fügt einen neuen Spieler zur FloatingWorld hinzu. Sie ist ebenfalls statisch und wird ebenfalls auch über den Klassennamen aufgerufen.

  • Aufruf von FloatingWorld.movePlayerLeft(0):

    Diese Methode bewegt einen, per numerischen Parameter ausgewählten, Spieler um einen festen Wert nach links. Auch diese Methode ist statisch und muss direkt über den Klassennamen vor dem Punkt aufgerufen werden. In diesem Beispiel entspricht 0 dem Spieler, der am längsten in der Welt existiert.

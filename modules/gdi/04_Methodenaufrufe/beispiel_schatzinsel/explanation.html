Erklärung

  • Aufruf von TreasureIsland.createMap():

    Die Klassenmethode erstellt die Karte der Schatzinsel. Sie gehört zur Klasse TreasureIsland. Weil es eine Klassenmethode (auf der API-Seite von TreasureIsland mit static ausgezeichnet) ist, wird sie über den Klassennamen vor dem Punktaufgerufen. Sie hat keine Parameter, leere Klammern sind aber trotzdem notwendig.

  • Aufruf von TreasureIsland.land():

    Das Schiff segelt an den Steg die Fuigur geht an Land. Auch diese Methode ist static und hat weder einen Parameter noch ein Ergebnis.

  • Aufruf von TreasureIsland.walk(TreasureIsland.NORTH, 5):

    Die Methode erwartet zwei Parameter: die Richtung und die Anzahl der Schritte. Die Richtung wird mit der Klassenkonstante TreasureIsland.NORTH (siehe API Beschreibung) angegeben. Wie bei Methoden steht vor dem Punkt wegen static der Klassenname, nach dem Punkt dann der Name des Attributs (hier eine Konstante vom Typ byte).

  • Aufruf von TreasureIsland.dig():

    Der Pirat gräbt an seiner aktuellen Position. Steht er auf dem X, springt die Schatztruhe aus dem Boden und auf der Konsole wird Schatz gefunden! ausgegeben.

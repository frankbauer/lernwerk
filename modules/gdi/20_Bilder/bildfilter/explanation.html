Erklärung

Das Ergebnis wird in ein neues Feld output geschrieben. Würde man die neuen Grauwerte direkt in img.data ablegen, flössen bereits gefilterte Werte in die Berechnung der folgenden Pixel ein.

Für jedes Pixel (x, y), das nicht am Rand liegt, wird der Kernel mit seinem Mittelpunkt auf das Pixel gelegt: Die Versätze a (Spalte) und b (Zeile) laufen von -1 bis 1, jeder Nachbar img.data[x + a][y + b] wird mit dem Kernelwert KERNEL[b + 1][a + 1] multipliziert und aufsummiert. Beachten Sie die unterschiedliche Reihenfolge der Indizes: Bei Image steht die Spalte zuerst, beim Kernel die Zeile.

Die Randpixel haben keine vollständige Nachbarschaft, daher beginnen beide Schleifen bei 1 und enden vor height - 1 bzw. width - 1. Sie bleiben im Ergebnis 0 (schwarz).

Die Kernel wirken sehr unterschiedlich:

  • Weichzeichnen (Box-Filter): Alle neun Werte sind 1/9, das Ergebnis ist der Mittelwert der Nachbarschaft.
  • Kanten X/Y (Sobel-Filter): Die Summe der Kernelwerte ist 0. In gleichmäßigen Flächen ist das Ergebnis daher nahe 0, nur an Helligkeitsübergängen in x- bzw. y-Richtung entstehen große Werte. Negative Werte werden von save() auf 0 begrenzt, daher sind nur Kanten in einer Richtung (von hell nach dunkel) sichtbar.

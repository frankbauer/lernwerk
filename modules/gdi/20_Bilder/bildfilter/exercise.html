Aufgabe

Gegeben ist für diese Aufgabe ein Grauwertbild, das mit Hilfe der Klasse Image geladen werden kann. Außerdem kann unten ein Faltungskernel ausgewählt werden, den Sie im Programm als KERNEL (ein 3x3-Feld von double-Werten) erhalten.

Implementieren Sie eine diskrete Faltung, die aus dem gegebenen Bild und dem Kernel ein neues Bild erzeugt. Nach dem Ablauf des Programms wird das durch img referenzierte Bild als Ergebnis neben dem Quellbild angezeigt. Die Methoden der Klasse Image finden Sie im Reiter Image.

Hinweise:

  • Sie benötigen zunächst ein neues 2D-Feld für das Ergebnisbild. Beachten Sie, dass bei Image der erste Index die Spalte und der zweite die Zeile angibt.
  • Die Randpixel werden bei der Filterung ignoriert.
  • Nachdem die neu berechneten Grauwerte in diesem Feld abgelegt wurden, muss eine neue Image-Instanz angelegt und an img zugewiesen werden.

Eine Gruppe von 4 Personen möchte nebeneinander sitzen. Finden Sie für jede Reihe die längste Folge zusammenhängender freier Plätze und geben Sie alle Reihen aus, in die die Gruppe passt. Sie brauchen pro Reihe zwei Akkumulatoren: die Länge der aktuellen Folge (wird bei einem belegten Platz auf 0 zurückgesetzt) und die bisher längste Folge. 
for (int row = 0; row < seats.length; row++) {
    int run = 0;
    int longest = 0;
    for (int seat = 0; seat < seats[row].length; seat++) {
        if (seats[row][seat] == 0) {
            run++;
            if (run > longest) {
                longest = run;
            }
        } else {
            run = 0;
        }
    }
    if (longest >= 4) {
        System.out.println("Die Gruppe passt in Reihe " + (row + 1));
    }
}
Die längste freie Folge hat 3 Plätze (Reihe 3), die Gruppe passt also in keine Reihe. Ändern Sie die Belegung, damit es klappt.

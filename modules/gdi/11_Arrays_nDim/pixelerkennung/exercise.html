Aufgabe

Im Playground unten ist ein kleines neuronales Netz (TensorFlow.js) eingebaut, das einfache Formen erkennt: waagrechte Linie, senkrechte Linie, Kreuz, Plus und Kreis. Zeichnen Sie mit der Maus eine dieser Formen in das Raster.

Das Bild kommt als zweidimensionales Feld int[][] bild mit 10 Zeilen und 12 Spalten in Ihrem Programm an. Jeder Eintrag ist die Helligkeit eines Pixels von 0 (leer) bis 255 (voll). Das Netz kann aber nur eine lange Liste von Zahlen verarbeiten. Ergänzen Sie die Methode zuVektor so, dass sie

  • ein neues Feld double[] mit Zeilen * Spalten Einträgen erzeugt,
  • die Pixel zeilenweise hineinkopiert: erst alle Pixel der Zeile 0, dann alle der Zeile 1 usw., und
  • jeden Wert dabei auf den Bereich 0.0 bis 1.0 umrechnet (durch 255.0 teilen).

Das Pixel bild[z][s] landet also an der Stelle z * spalten + s. Für ein Bild mit 2 Zeilen und 3 Spalten:

bild   = { {0, 255, 0}, {255, 255, 255} }
vektor = { 0.0, 1.0, 0.0, 1.0, 1.0, 1.0 }

Führen Sie das Programm aus: Das Netz erhält genau das Feld, das zuVektor zurückgibt. Rechts sehen Sie, wie das Netz Ihr Feld „sieht“, und mit welcher Wahrscheinlichkeit es welche Form erkennt.

Hinweis: Verwenden Sie bild.length und bild[0].length statt fester Zahlen.

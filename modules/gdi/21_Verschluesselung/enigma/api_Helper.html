class Helper

Hilfsmethoden für die Walzen. Alle Methoden sind Klassenmethoden (static).

Methoden:

  • static int[] getMapping()
Gibt ein Mapping-Array für die 26 Buchstaben a...z zurück.
Mehrfache Aufrufe geben unterschiedliche Mappings zurück.
  • static int getIndexFromChar(char c)
Gibt den Index zum übergebenen Buchstaben zurück: a...z -> 0...25
(funktioniert auch mit Großbuchstaben). Für andere Zeichen wird -1 zurückgegeben.
  • static char getCharFromIndex(int index)
Gibt den Buchstaben zum übergebenen Index zurück: 0...25 -> a...z
(nur Kleinbuchstaben). Für andere Werte wird '?' zurückgegeben.

Aufgabe

In dieser Aufgabe programmieren Sie noch einmal die Kirschenessen-Spielsequenz, diesmal allerdings bequemer mit Instanzmethoden der neuen Klasse Player. Verwenden Sie dazu die folgenden Instanzmethoden der Klasse Player und die Klassenmethoden der Klasse FloatingWorld (beachten Sie das Schlüsselwort static!). Eine Beschreibung finden Sie auch in den Reitern FloatingWorld und Player.

FloatingWorld

  • static void show() Zeigt die Welt an.
  • static void removePlayer(Player p) Löscht den übergebenen Spieler.

Player

  • Player() (Konstruktor) Erzeugt einen neuen Spieler.
  • void moveLeft() Spieler bewegt sich nach links.
  • void moveRight() Spieler bewegt sich nach rechts.
  • int getID() Spieler gibt seine ID zurück.

Gehen Sie wie folgt vor:

  1. Erstellen Sie zwei neue Spieler-Objekte.
  2. Bewegen Sie den pinken Spieler nach rechts.
  3. Bewegen Sie den roten Spieler nach rechts (dieser sollte nun die Kirsche aufnehmen).
  4. Löschen Sie den pinken Spieler.
  5. Bewegen Sie den roten Spieler nach links.

Auf dem Spielfeld sollte am Ende des Durchlaufs der rote Spieler an seiner Ausgangsposition (weiß gestrichelter Umriss) mit der Kirsche über seinem Kopf stehen. In der Ausgabe unter dem Spielfeld sehen Sie, ob Ihre Befehlsfolge richtig ist.

Erklärung

Im Gegensatz zur Variante mit Klassenmethoden arbeiten Sie hier mit Objekten. Jeder Spieler ist eine Instanz der Klasse Player, und Sie merken sich die Referenz darauf in einer Variablen.

  • Spieler erzeugen: Player pink = new Player(); und Player red = new Player();. Der zuerst erzeugte Spieler ist pink, der zweite rot. Die Namen der Variablen können Sie frei wählen, sprechende Namen machen den Code aber deutlich lesbarer.
  • Nach rechts bewegen: pink.moveRight(); und red.moveRight();. Die Instanzmethode wird über die Referenz aufgerufen und wirkt nur auf genau dieses Objekt. Der rote Spieler landet dabei auf der Kirsche und nimmt sie auf.
  • Pinken Spieler löschen: FloatingWorld.removePlayer(pink);. Das ist eine Klassenmethode, sie wird daher über den Klassennamen aufgerufen. Als Parameter bekommt sie die Referenz auf das zu löschende Objekt.
  • Roten Spieler nach links bewegen: red.moveLeft();. Die Falle aus der Variante mit Klassenmethoden gibt es hier nicht mehr: Zwar ändert sich die ID des roten Spielers nach dem Löschen von 1 auf 0 (probieren Sie es mit System.out.println(red.getID()); aus), die Referenz red zeigt aber weiterhin auf dasselbe Objekt. Sie müssen sich also nicht um Indizes kümmern.

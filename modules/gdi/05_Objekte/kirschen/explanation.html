Erklärung

Im Gegensatz zur Variante mit Klassenmethoden arbeiten Sie hier mit Objekten. Jede Spielfigur ist eine Instanz der Klasse Player, und Sie merken sich die Referenz auf diese Instanzen in Variablen.

  • Spieler erzeugen: new Player() erzeugt ein neues Objekt. Eine Referenz auf dieses Objekt können sie sich mit Player pink = in einer Variablen speichern. Dasselbe gilt für Player red = new Player();. Die zuerst erzeugte Spielfigur ist pink, die zweite rot. Die Namen der Variablen können Sie aber frei wählen, sprechende Namen machen den Code allerdings lesbarer.
  • Nach rechts bewegen: pink.moveRight(); und red.moveRight();. Die Instanzmethode wird über die Referenz (pink. bzw. red.) aufgerufen und wirkt nur auf genau das von der Variablen referenzierte Objekt. Der pinke Spieler landet durch die Bewegung auf der Kirsche und nimmt diese auf.
  • Pinke Spielfigur löschen: FloatingWorld.removePlayer(pink);. removePlayer ist eine Klassenmethode, sie wird daher über den Klassennamen FloatingWorld. aufgerufen. Als Eingabeparameter bekommt die Methode eine Referenz auf das zu löschende Objekt übergeben. Die Kirsche verschwindet zusammen mit der pinken Spielfigur.
  • Roten Spieler nach links bewegen: red.moveLeft(); bewegt die rote Spielfigur wieder nach links an ihre Ausgangsposition. Die Referenz red zeigt auch nach dem Löschen der pinken Spielfigur weiterhin auf dasselbe Objekt.

Erklärung

  • Aufruf von FloatingWorld.show():

    Diese Klassenmethode zeigt die FloatingWorld an. Sie wird wie bisher über den Klassennamen aufgerufen.

  • Erzeugung von Spielerinstanzen mit new:

    new Player() erzeugt ein neues Objekt der Klasse Player. Das Ergebnis ist eine Referenz auf dieses Objekt, die in der Referenzvariablen kara bzw. lee abgelegt wird. Über diese Variablen können wir die beiden Objekte später gezielt ansprechen.

    Player kara = new Player();
Player lee = new Player();
  • Spieler zur Welt hinzufügen:

    FloatingWorld.addPlayer(kara) ist eine Klassenmethode, die ein Player-Objekt als Parameter erhält. Erst danach ist der Spieler in der Welt zu sehen.

  • Bewegung eines Spielers:

    kara.moveLeft(); Die Instanzmethode moveLeft() wird auf dem von kara referenzierten Objekt aufgerufen. Dadurch ändert sich der Zustand (die x-Koordinate) genau dieses Objekts, lee bleibt stehen.

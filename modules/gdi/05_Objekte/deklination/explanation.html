Erklärung

  • new DateParser(args) erzeugt eine neue Instanz der Klasse DateParser. Mit DateParser parser = wird die Referenz darauf in der Variablen parser gespeichert. Als Parameter wird dem Konstruktor args übergeben, ein Array mit den Programmargumenten der main-Methode. Darin steht das eingestellte Datum aus der Aufgabenstellung.
  • final int D = parser.getDayOfYear(); ruft die Instanzmethode getDayOfYear über die zuvor angelegte Variable parser auf. Anders als bei einer Klassenmethode (z.B. Math.cos) steht vor dem Punkt also kein Klassenname, sondern eine Variable, die auf ein Objekt verweist.
  • System.out.println("Tag im Jahr: " + D); gibt den so gelesenen Tag auf der Konsole aus.
  • final double orbitalAngle = Math.toRadians((360.0 * (D + 10)) / 365.0); berechnet das Argument für den Kosinus. Wichtig ist 360.0 statt 360: Sonst würde mit ganzen Zahlen gerechnet und die Division den Nachkommaanteil abschneiden. Da Math.cos den Winkel im Bogenmaß erwartet, wird das Ergebnis mit Math.toRadians umgerechnet.
  • Die Neigung der Erdachse ist in der vorgegebenen Konstanten EARTH_TILT_RAD bereits im Bogenmaß gespeichert. final double declination = EARTH_TILT_RAD * Math.cos(orbitalAngle); berechnet nun das geforderte ergebnis, das ebenfalls im Bogenmaß gespeichert ist.
  • System.out.println("Deklination: " + Math.toDegrees(declination)); rechnet die Deklination in Grad um und gibt sie aus.

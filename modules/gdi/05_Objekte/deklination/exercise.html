Aufgabe

In dieser Aufgabe bestimmen Sie die Deklination δ der Erde für den unten eingestellten Tag. Es gilt:

δ = − 23.44° ⋅ cos ( 360°⋅(D+10) 365 )

Dabei ist D der Tag des Jahres (der 1. Januar entspricht D=1, der 31. Dezember in einem Schaltjahr D=366).

Tipp: Achten Sie beim Umsetzen der Formel in Java darauf, dass sie nicht aus versehen eine Ganzzahl-division durchführen.

Mit Hilfe der Klasse DateParser können Sie in Ihrem Programm auslesen, welches Datum unten eingestellt wurde. Erzeugen Sie dazu eine Instanz von DateParser und rufen Sie deren Instanzmethode getDayOfYear() auf. Eine Beschreibung finden in der Dokumentation von DateParser.

Datum:

Ihr Programm soll den gelesenen Tag des Jahres sowie die berechnete Deklination (in Grad) auf der Konsole ausgeben. Für den 26. April 2024 sieht die Ausgabe zum Beispiel so aus:

Tag im Jahr: 117
Deklination: 13.531715491972486

Tipp: Math.cos erwartet den Winkel im Bogenmaß. Mit Math.toRadians und Math.toDegrees können Sie zwischen Grad und Bogenmaß umrechnen.

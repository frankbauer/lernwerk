class DateParser

Hilfsklasse, die das oben eingestellte Datum aus den Programmargumenten liest.

Konstruktor:

  • public DateParser(String[] args)
Erstellt eine neue Instanz und verarbeitet die in args übergebenen Werte. args wird Ihrer
main-Methode als Parameter übergeben und kann wie eine lokale Variable verwendet werden.

Instanzmethoden:

  • public int getDayOfYear()
Gibt den eingestellten Tag des Jahres D zurück. Der 1. Januar hat zum Beispiel den Wert 1, der 30. Dezember hat in
einem Schaltjahr den Wert 365.

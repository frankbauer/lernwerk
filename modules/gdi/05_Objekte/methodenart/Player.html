Beschreibung

Diese Klasse repräsentiert einen Spieler in einer virtuellen Welt. Jeder Spieler hat einen spezifischen Typ (ein Aussehen) sowie eine eindeutige ID und kann sich innerhalb der Welt bewegen.

Öffentliche Methoden

  • public void moveLeft()
    Bewegt den Spieler um einen festen Wert nach links.
  • public int getID()
    Gibt die ID des Spielers zurück.
  • public void remove()
    Entfernt den Spieler aus der Welt.
  • public static Player playerWithID(int id)
    Gibt den Spieler mit der angegebenen ID zurück.
  • public static void printAllPlayers()
    Gibt alle Spieler auf der Konsole aus.

Erklärung

Ob eine Instanz- oder eine Klassenmethode aufgerufen wird, erkennen Sie daran, was direkt vor dem Punkt steht:

  • Klassenmethode (static): Vor dem Punkt steht ein Klassenname, z.B. FloatingWorld.(), Math. oder Player.. Für den Aufruf wird kein Objekt benötigt.
  • Instanzmethode: Vor dem Punkt steht ein Ausdruck der zu einer Objektreferenz auswertet. Das kann eine Variable sein, die auf ein Objekt verweist (p.), ein neu erzeugtes Objekt (new Vec2D().) oder das Ergebnis eines anderen Methodenaufrufs (Player.playerWithID(3).).

Achten Sie auf verschachtelte Aufrufe:

  • Player.playerWithID(3).remove() Hier stehen zwei Aufrufe hintereinander. playerWithID ist (wenn man den Aufruf ansieht) eine Klassenmethode der Klasse Player. Methoden können ie eine Klasse zurückgeben, wenn also auf dem Ergebnis eines Methodenaufrufs wine weitere Methode aufgerufen wird (hier .remove()) muss diese Methode eine Instanzmethodesein. Der Aufruf playerWithID(3) liefert im Beispiel ein Player-Objekt zurück. Auf diesem Objekt wird dann die Instanzmethode remove aufgerufen. Dass der Name einer Klasse am Anfang der Zeile steht, sagt also noch nichts über den unterstrichenen Aufruf aus.
  • FloatingWorld.removePlayer(p.getID()) Der äußere Aufruf removePlayer ist eine Klassenmethode. Der Parameter-Ausdruck p.getID() ist dagegen ein Aufruf der Instanzmethode getID auf dem Objekt p.
  • Eine Klasse kann beide Arten von Methoden haben: Player.printAllPlayers() ist eine Klassenmethode, p.moveLeft() eine Instanzmethode derselben Klasse Player.

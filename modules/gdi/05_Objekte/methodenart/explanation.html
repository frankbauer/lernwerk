Erklärung

Ob eine Instanz- oder eine Klassenmethode aufgerufen wird, erkennen Sie daran, was direkt vor dem Punkt steht:

  • Klassenmethode (static): Vor dem Punkt steht ein Klassenname, z.B. FloatingWorld.addPlayer(), Math.random() oder Player.printAllPlayers(). Für den Aufruf wird kein Objekt benötigt.
  • Instanzmethode: Vor dem Punkt steht ein Objekt. Das kann eine Variable sein, die auf ein Objekt verweist (p.moveLeft()), ein neu erzeugtes Objekt (new Vec2D().toString()) oder das Ergebnis eines anderen Methodenaufrufs (Player.playerWithID(3).remove()).

Achten Sie auf verschachtelte Aufrufe:

  • Player.playerWithID(3).remove() Hier stehen zwei Aufrufe hintereinander. playerWithID ist eine Klassenmethode der Klasse Player und liefert ein Player-Objekt. Auf diesem Objekt wird dann die Instanzmethode remove aufgerufen. Dass der Name einer Klasse am Anfang der Zeile steht, sagt also noch nichts über den unterstrichenen Aufruf aus.
  • FloatingWorld.removePlayer(p.getID()) Der äußere Aufruf removePlayer ist eine Klassenmethode. Der Parameter p.getID() ist dagegen ein Aufruf der Instanzmethode getID auf dem Objekt p.
  • Eine Klasse kann beide Arten von Methoden haben: Player.printAllPlayers() ist eine Klassenmethode, p.moveLeft() eine Instanzmethode derselben Klasse Player.

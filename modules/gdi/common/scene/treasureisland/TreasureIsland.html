class TreasureIsland

Beschreibung

Die Klasse TreasureIsland zeigt eine Schatzinsel. Ein Pirat landet mit seinem Schiff an der Südküste und kann über die Insel laufen. Das X auf der Karte markiert die Stelle, an der der Schatz vergraben ist. Alle Methoden und Attribute sind statisch (Klassenmethoden und Klassenattribute).

Klassenattribute (Konstanten)

  • public static final byte NORTH
    Richtung Norden (auf der Karte nach oben).
  • public static final byte EAST
    Richtung Osten (nach rechts).
  • public static final byte SOUTH
    Richtung Süden (nach unten).
  • public static final byte WEST
    Richtung Westen (nach links).

Klassenmethoden

  • public static void createMap()
    Erstellt die Karte der Schatzinsel und zeigt sie an.
  • public static void land()
    Das Schiff segelt an den Steg an der Südküste, der Pirat geht an Land.
  • public static void walk(byte direction, int steps)
    Der Pirat läuft steps Felder in die Richtung direction (NORTH, EAST, SOUTH oder WEST). Am Wasser bleibt er stehen.
  • public static void dig()
    Der Pirat gräbt an seiner aktuellen Position. Steht er auf dem X, findet er den Schatz: Die Truhe springt in das Feld über ihm.

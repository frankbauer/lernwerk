Erklärung

In der Beispiellösung wird jeder Ausdruck einer Variablen zugewiesen, deren Typ genau dem Typ des Ausdrucks entspricht. Das Programm erzeugt beim Ausführen keine Ausgabe.

Für arithmetische Operatoren (+ - * / %) gilt vereinfacht:

Der größere der beiden Typen bestimmt den Ergebnisdatentyp, in der Reihenfolge byte → short → int → long → float → double.

  • 3 + 4 ergibt int. 3.0f - 4.0 ergibt double, denn 4.0 ist ein double-Literal. 3.0f - 4 ergibt float. 5.0 / 4 ergibt double. 400L % 3 ergibt long.
  • 'A' ist ein char, "A" ein String. Einfache Anführungszeichen stehen für genau ein Zeichen, doppelte für eine Zeichenkette.
  • (long)4.9 / (short)-200.0 Die Casts wirken nur auf den direkt folgenden Wert, hier also (long)4.9 und (short)-200.0, nicht auf den ganzen Ausdruck. Der short-Wert wird zu long.
  • 12.5f * 'A' und 'A' + 'B' char wird zu int. Bei 12.5f * 'A' bestimmt danach float den Ergebnisdatentyp. 'A' + 'B' ergibt int, also die Zahl 131 und nicht den Text "AB".
  • Vergleiche (< > == ...) und logische Verknüpfungen (&& ||) ergeben immer boolean, egal welchen Typ die verglichenen Werte haben.
  • "Hallo" + 3 Ist einer der Operanden von + ein String, wird verkettet. Das Ergebnis ist also wieder ein String.

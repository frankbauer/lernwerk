Erklärung

  • for-Schleife mit Index: Wie bei einem Feld läuft i von 0 bis list.size() - 1. Statt list[i] schreibt man bei Listen list.get(i).
    Bei einer LinkedList ist das allerdings langsam: get(i) muss sich jedes Mal vom Anfang der Liste bis zum i-ten Element durchhangeln.
  • for-each-Schleife: for (String s : list) liefert nacheinander jedes Element, ohne dass man einen Index braucht. Intern verwendet sie einen Iterator, der sich die aktuelle Position merkt. Bei einer LinkedList ist das die übliche Variante.
  • forEach-Methode: Hier übergibt man keine Schleife, sondern eine Funktion, die für jedes Element aufgerufen wird. s -> System.out.print(s + " ") ist ein Lambda-Ausdruck: links vom Pfeil steht der Parameter (das aktuelle Element), rechts, was damit passieren soll.

Statt list.stream().forEach(...) kann man auch direkt list.forEach(...) schreiben.

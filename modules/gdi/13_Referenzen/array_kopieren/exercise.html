Aufgabe

  1. Erstellen Sie ein int-Feld mit fünf beliebigen Werten.
  2. Kopieren Sie das Feld in eine zweite Variable. Die Werte sollen dabei vom Programm kopiert werden, schreiben Sie sie also nicht ein zweites Mal in den Code.
  3. Multiplizieren Sie alle Werte im zweiten Feld mit 2.
  4. Geben Sie den Inhalt beider Felder aus.

Für das Feld {1, 2, 3, 4, 5} soll die Ausgabe z.B. so aussehen:

Array 1:
1 2 3 4 5 
Array 2:
2 4 6 8 10

Setzen Sie den Startwert von min auf 0 und ändern Sie die Buchungen zu {50, -20, 30}. Welcher tiefste Stand wird ausgegeben? Welcher wäre richtig? Ausgegeben wird 0, obwohl das Konto nie unter 100 gefallen ist (Stände 150, 130, 160). Der Startwert eines Minimums muss ein Wert sein, der tatsächlich vorkommt.
Zählen Sie zusätzlich, nach wie vielen Buchungen das Konto im Minus war.

for (int i = 0; i < bookings.length; i++) {
    /*...*/
    if (balance < 0) {
        negative++;
    }
}
System.out.println("Buchungen im Minus: " + negative);

Geben Sie zusätzlich den Index der Buchung aus, nach der der tiefste Stand erreicht wurde. Welcher Index wird ausgegeben, wenn der tiefste Stand zweimal vorkommt (ändern Sie dazu die letzte Buchung zu -60)? Probieren Sie es mit < und mit <= aus. 
int minIndex = -1;
for (int i = 0; i < bookings.length; i++) {
    balance += bookings[i];
    if (balance < min) {
        min = balance;
        minIndex = i;
    }
}
Mit < wird das erste Vorkommen gemerkt (Index 3), mit <= das letzte (Index 8). Der Startwert -1 bedeutet: Der Startbetrag war der tiefste Stand.

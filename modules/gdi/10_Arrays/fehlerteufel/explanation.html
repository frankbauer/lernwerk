Erklärung

  1. int summe = 1; → int summe = 0;: Eine Summe beginnt bei 0, sonst ist das Ergebnis immer um eins zu groß.
  2. i = a.length → i < a.length: Die Schleifenbedingung muss ein Wahrheitswert sein. = ist eine Zuweisung (Syntaxfehler), außerdem darf i höchstens a.length - 1 werden.
  3. i++) ; { → i++) {: Das Semikolon beendet die Schleife sofort mit einer leeren Anweisung. Der Block danach würde nur einmal ausgeführt, und i wäre dort nicht bekannt.
  4. a[i] % 2 == 2 → a[i] % 2 == 0: Der Rest einer Division durch 2 ist nie 2. Gerade Zahlen haben den Rest 0.
  5. summe = a[i] * a[i]; → summe += a[i] * a[i];: Das Quadrat muss zur Summe addiert werden, statt sie zu überschreiben.
  6. return summe * summe; → return summe;: Quadriert werden die einzelnen Zahlen, nicht die Summe.
  7. int a = { ... }; → int[] a = { ... };: Ein Feldliteral kann nur einer Feldvariable zugewiesen werden.

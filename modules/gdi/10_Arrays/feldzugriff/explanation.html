Erklärung

Ein Feld der Länge n hat die Indizes 0 bis n - 1. Wird ein anderer Index verwendet, wirft Java eine ArrayIndexOutOfBoundsException. In der Beispiellösung gibt jede Schleife statt der Werte die verwendeten Indizes aus.

Alle Elemente besuchen:

  • a) i läuft von 0 bis 99, genau die Indizes des Feldes.
  • b) i % b.length liegt immer zwischen 0 und 3. Die Indizes werden mehrfach besucht, aber nie überschritten.
  • e) und f) Die Bedingung vor dem Zugriff verhindert zu große Indizes. break beendet die Schleife, continue überspringt die restlichen Durchläufe. Beides erreicht hier dasselbe.
  • g) Nach dem Zugriff auf den letzten Index 4 beendet break die Schleife.
  • i) Die Indizes 0 und 1 werden über i[t-1] und i[t-2] gelesen, 2 bis 5 über i[t].
  • m) Die Schleife läuft rückwärts. Bis u bei 4 angekommen ist, wird der Zugriff mit continue übersprungen, danach werden 4 bis 0 besucht.

IndexOutOfBoundsException:

  • c) x beginnt bei c.length, also bei 4. Das ist schon der erste ungültige Index.
  • d) Im letzten Durchlauf ist t = 4, geschrieben wird dann auf d[6].
  • h) Anders als in g) steht hier continue. Das beendet die Schleife nicht, und h[5] wird gelesen.
  • k) l beginnt beim letzten Index 29, wird aber mit l++ erhöht. Der nächste Zugriff ist k[30].

Endlosschleife:

  • j) Im Rumpf wird l mit l % j.length immer wieder auf einen Wert zwischen 0 und 3 gesetzt. l < 100 ist daher immer erfüllt.

Keine oder einige Elemente:

  • l) Schon im ersten Durchlauf ist v = 50 >= l.length, und break beendet die Schleife, bevor ein Element besucht wird.

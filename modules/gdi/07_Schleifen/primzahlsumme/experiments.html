Überlegen Sie zuerst, was für die Grenzen 101, 3 und 2 ausgegeben wird. Probieren Sie es danach aus. 101: Summe 100 (9 Primzahlen, die letzte ist 23).
3: Summe 2 (1 Primzahl, die letzte ist 2).
2: Summe 0 (0 Primzahlen, die letzte ist 0). Die Schleife läuft gar nicht, alle Akkumulatoren behalten ihren Startwert.
Ersetzen Sie die Bedingung durch sum < limit. Was ändert sich für die Grenze 100? Die Ausgabe ist Summe: 100 (9 Primzahlen, die letzte ist 23). Die Bedingung wird geprüft, bevor 23 addiert wird. Zu diesem Zeitpunkt ist 77 < 100 noch wahr. Die Summe liegt danach aber nicht mehr unter der Grenze.
Legen Sie eine Variable int maxCount = 5; an. Es sollen jetzt höchstens maxCount Primzahlen addiert werden, und die Summe soll weiterhin unter limit bleiben. Welche der beiden Bedingungen beendet die Schleife für limit = 100 und welche für limit = 20? Beide Bedingungen müssen gelten, damit weitergemacht wird. Sie werden mit && verknüpft. 
int maxCount = 5;
while (sum + candidate < limit && count < maxCount) {
    /*...*/
}
Für limit = 100 endet die Schleife wegen maxCount: Summe 28 (5 Primzahlen, die letzte ist 11). Für limit = 20 endet sie wegen der Grenze: Summe 17 (4 Primzahlen, die letzte ist 7).
Ändern Sie das Programm so, dass nur jede zweite Primzahl addiert wird (2 + 5 + 11 + 17 + …). Sie brauchen einen weiteren Zähler für alle gefundenen Primzahlen, auch die nicht addierten. Überlegen Sie, ob sum + candidate < limit noch die richtige Abbruchbedingung ist. 
int found = 0;
while (sum + candidate < limit) {
    if (Prim.isPrim(candidate)) {
        if (found % 2 == 0) {
            sum += candidate;
            count++;
            last = candidate;
        }
        found++;
    }
    candidate++;
}
Die Bedingung stimmt weiterhin: Die nächste addierte Primzahl ist mindestens so groß wie candidate. Für limit = 100 ergibt sich Summe 89 (6 Primzahlen, die letzte ist 31).

Erklärung

  • int sum = 0; ist der Akkumulator. Er wird vor der Schleife mit 0 angelegt und sammelt in jedem Durchlauf eine Ziffer auf.
  • int rest = number; ist eine Kopie der Zahl. number selbst ist final und wird für die Ausgabe noch gebraucht.
  • while (rest > 0) Wie oft die Schleife läuft, hängt von der Anzahl der Ziffern ab. Die ist vorher nicht bekannt, deshalb eignet sich eine while-Schleife.
  • sum += rest % 10; addiert die letzte Ziffer, rest /= 10; entfernt sie (ganzzahlige Division).

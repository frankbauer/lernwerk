Aufgabe

In dieser Aufgabe soll die Spielfigur wieder die Kirsche aufsammeln und anschließend zur Startposition (weiß gestrichelter Umriss) zurücklaufen. Verwenden Sie zur Lösung geeignete Schleifen. Ihnen stehen dazu die folgenden Klassenmethoden der Klasse Controller zur Verfügung (siehe auch Reiter Controller):

  • static void movePlayerLeft() Bewegt den Spieler nach links.
  • static void movePlayerRight() Bewegt den Spieler nach rechts.
  1. Bewegen Sie zunächst den Spieler 10-mal nach rechts.
  2. Anschließend soll der Spieler exakt zum Startpunkt zurücklaufen. Allerdings unterscheidet sich die Schrittlänge nach links und nach rechts, sodass Sie die Schrittanzahl nicht einfach abzählen sollen. Verwenden Sie die folgenden zusätzlichen Methoden, um den Spieler automatisch zum Ziel zu bringen:
    • static boolean isPlayerAtTarget() Prüft, ob der Spieler am Ziel angekommen ist.
    • static boolean isPlayerLeftOfTarget() Prüft, ob der Spieler links vom Ziel steht.
    • static boolean isPlayerRightOfTarget() Prüft, ob der Spieler rechts vom Ziel steht.
    Programmieren Sie die Laufbewegung in Abhängigkeit dieser drei Methoden (und nicht fest)!

In der Ausgabe unter dem Spielfeld sehen Sie, ob Ihre Befehlsfolge richtig ist.

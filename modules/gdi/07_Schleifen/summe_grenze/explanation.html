Erklärung

  • int sum = 0; int n = 0; sum ist der Akkumulator für die Summe, n der aktuelle Summand. Beide werden vor der Schleife deklariert, damit sie nach der Schleife noch verfügbar sind.
  • while (true) Die Bedingung ist immer wahr, die Schleife würde also endlos laufen. Das ist hier gewollt: Das Ende wird im Rumpf entschieden.
  • n++; bestimmt den nächsten Summanden.
  • if (sum + n >= limit) break; Bevor addiert wird, wird geprüft, ob die neue Summe die Grenze erreichen würde. Wenn ja, verlässt break sofort die Schleife, und sum enthält noch die letzte Summe unterhalb der Grenze. Würde man zuerst addieren und danach prüfen, stünde in sum schon der erste Wert, der die Grenze überschreitet.
  • sum += n; Nur wenn die Grenze noch nicht erreicht ist, wird der Summand aufaddiert.

Für limit = 1000 wird bis n = 44 addiert (sum = 990). Bei n = 45 wäre 990 + 45 = 1035 >= 1000, die Schleife bricht ab.

Dasselbe geht auch ohne Endlosschleife, mit der Bedingung direkt im Schleifenkopf: while (sum + n + 1 < limit) { n++; sum += n; }. Die Variante mit break ist oft leichter zu lesen, wenn die Abbruchbedingung erst im Rumpf berechnet werden kann.

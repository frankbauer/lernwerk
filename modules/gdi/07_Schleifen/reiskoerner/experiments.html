Experimente

Ändern Sie den Datentyp von total und grains in int. Welches Ergebnis erhalten Sie für 32 Felder? Ab wie vielen Feldern ist das Ergebnis falsch? Der größte int-Wert ist 2147483647, also 231 − 1. Für 32 Felder wird -1 ausgegeben. Bis 31 Felder ist das Ergebnis richtig (231 − 1 passt gerade noch). Danach läuft int über.
Wählen Sie 63 und danach 64 Felder (mit long). Was fällt Ihnen auf? Bei 63 Feldern ergibt sich genau Long.MAX_VALUE = 9223372036854775807. Bei 64 Feldern läuft auch long über, und es wird -1 ausgegeben. Mit double als Datentyp für total und grains erhalten Sie eine (gerundete) Zahl.
Geben Sie nach der Schleife zusätzlich aus, wie viele Körner auf dem letzten Feld liegen. Prüfen Sie genau, welchen Wert grains nach der Schleife hat. Nach dem letzten Durchlauf wurde grains noch einmal verdoppelt. 
System.out.println("Auf dem letzten Feld liegen " + (grains / 2) + " Körner.");
Wie viele Felder braucht man, bis insgesamt mindestens eine Million Körner auf dem Brett liegen? Verwenden Sie dafür eine while-Schleife. 
long total = 0;
long grains = 1;
int count = 0;
while (total < 1000000) {
    total += grains;
    grains *= 2;
    count++;
}
System.out.println(count + " Felder");
Es sind 20 Felder (220 − 1 = 1048575).

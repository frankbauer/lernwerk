Erklärung

Eine Summe mit vielen Summanden lässt sich nicht in einer einzigen Zeile hinschreiben, wenn die Anzahl N variabel ist. Stattdessen wird sie in einer Schleife Stück für Stück aufgebaut:

  • double sum = 0; Der Akkumulator wird vor der Schleife deklariert und mit 0 initialisiert, dem neutralen Element der Addition. Stünde die Deklaration im Schleifenrumpf, würde die Variable in jedem Durchlauf neu angelegt und wäre nach der Schleife nicht mehr sichtbar.
  • for (int k = 1; k <= N; k++) Die Zählvariable k läuft von 1 bis einschließlich N und ist gleichzeitig der Faktor des jeweiligen Vielfachen.
  • sum += k * Math.PI; In jedem Durchlauf wird der nächste Summand zum bisherigen Zwischenergebnis addiert. sum += x ist eine Kurzschreibweise für sum = sum + x.

Nach den Durchläufen für k = 1, 2, ..., 10 enthält sum den Wert π + 2π + ... + 10π = 55π ≈ 172.79. Probieren Sie andere Werte für N aus: Das Ergebnis ist immer N · (N + 1) / 2 · π.

Erklärung

Das Programm führt arithmetische Operationen (Addition, Subtraktion und Ganzzahldivision) auf zwei Ganzzahlen a und b aus und gibt die Ergebnisse aus.

  • public class ArithmeticOperations { Definiert eine öffentliche Klasse mit dem Namen ArithmeticOperations, welche die Funktionen für arithmetische Operationen enthält.
  • public static void main(String[] args) { Die Hauptmethode des Programms, die immer beim Start des Programmes ausgeführt wird.
  • int a = 11; Deklaration und Initialisierung einer Variable a mit dem Wert 11.
  • int b = 3; Deklaration und Initialisierung einer Variable b mit dem Wert 3.
  • System.out.println("a=" + a + ", b=" + b + "\n"); Ausgabe der Werte für die Variablen a und b mit einer zusätzlichen Leerzeile (wird durch "\n" eingefügt).
  • int sum = a + b; Berechnung der Summe der Variablen a und b und Speicherung des Ergebnisses in der Variable sum.
  • System.out.println("Summe: " + sum); Ausgabe der Summe mit einer Textzeile "Summe: " und dem Wert der Variable sum.
  • int difference = a - b; Berechnung der Differenz zwischen den Variablen a und b und Speicherung des Ergebnisses in der Variable difference.
  • System.out.println("Differenz: " + difference); Ausgabe der Differenz mit einer Textzeile "Differenz: " und dem Wert der Variable difference.
  • int quotient = a / b; Berechnung des Quotienten von a durch b und Speicherung des Ergebnisses in der Variable quotient. Hier findet eine Ganzzahldivision statt, bei der der Nachkommaanteil des Ergebnisses ignoriert wird.
  • System.out.println("Quotient: " + quotient); Ausgabe des Quotienten mit einer Textzeile "Quotient: " und dem Wert der Variable quotient.

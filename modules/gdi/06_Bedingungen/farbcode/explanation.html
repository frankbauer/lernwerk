Erklärung

Für jede bekannte Farbe gibt es einen eigenen Fall. Die Fälle schließen sich gegenseitig aus, daher werden sie mit einer if ... else if ... else-Kette verbunden. Sobald eine Bedingung zutrifft, werden die übrigen nicht mehr geprüft.

  • equals statt ==: colorName ist eine Zeichenkette, also ein Objekt. == prüft nur, ob zwei Referenzen auf dasselbe Objekt zeigen. Der aus der Auswahlliste übergebene Text ist aber ein anderes Objekt als das Literal "RED", auch wenn beide den gleichen Inhalt haben. Den Inhalt vergleicht colorName.equals("RED").
  • Unbekannte Farben: Das abschließende else fängt alle Werte ab, für die keine der Bedingungen zutrifft, etwa ORANGE. Dann wird UNBEKANNT ausgegeben.

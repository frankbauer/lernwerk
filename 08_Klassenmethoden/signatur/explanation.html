Erklärung

Eine Methodendeklaration besteht in Java immer aus denselben Teilen, in fester Reihenfolge:

  1. Modifikatoren: public static. public macht die Methode öffentlich, static macht sie zur Klassenmethode.
  2. Rückgabetyp: boolean, weil die Methode einen Wahrheitswert zurückgibt.
  3. Methodenname: millFilledRectangle.
  4. Parameterliste in runden Klammern: (ServoController c, int x1, int y1, int x2, int y2). Jeder Parameter besteht aus Typ und Name, mehrere Parameter werden durch Kommas getrennt.
  5. Methodenrumpf in geschweiften Klammern: {/*...*/}.

Da alle Parameter außer ServoController c mit einem Komma beginnen, muss ServoController c direkt nach der öffnenden Klammer stehen. Die Reihenfolge der int-Parameter ist für den Compiler egal. Sinnvoll ist aber, die Koordinaten paarweise zu übergeben: zuerst (x1,y1) für die linke obere Ecke, dann (x2,y2) für die rechte untere Ecke.

Dass die Methode über mehrere Zeilen verteilt ist, stört den Compiler nicht. Zeilenumbrüche und Leerzeichen zwischen den Bestandteilen dürfen beliebig gesetzt werden. Üblich ist aber, die Signatur in eine Zeile zu schreiben, wie in der Beispiellösung.

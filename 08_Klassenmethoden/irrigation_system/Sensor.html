class Sensor

Beschreibung

Die Klasse Sensor liefert die Messwerte der im Gewächshaus verbauten Sensoren. Alle Methoden sind Klassenmethoden und werden daher direkt über den Klassennamen aufgerufen, z.B. Sensor.getSeason().

Konstanten

  • public static final int SPRING
    Jahreszeit Frühling
  • public static final int SUMMER
    Jahreszeit Sommer
  • public static final int AUTUMN
    Jahreszeit Herbst
  • public static final int WINTER
    Jahreszeit Winter

Methoden

  • public static int getSeason()
    Gibt die aktuelle Jahreszeit als Zahlenwert codiert zurück (siehe Konstanten). Während eines Programmlaufs liefert die Methode immer dieselbe Jahreszeit.
  • public static String getSeasonName(int season)
    Gibt den Namen der übergebenen Jahreszeit als Text zurück.
  • public static int getMoisture(String plant)
    Misst die Bodenfeuchte im Topf der übergebenen Pflanze und gibt sie in Prozent (0 bis 100) zurück.

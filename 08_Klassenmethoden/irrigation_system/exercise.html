Aufgabe

In dieser Aufgabe wollen Sie die Bewässerung Ihrer Pflanzen automatisieren. Durch die Automatisierung stellen Sie sicher, dass die Pflanzen immer die richtige Menge an Wasser und Dünger erhalten, und können unbesorgt ein paar Tage in den Urlaub fahren, ohne dass sich jemand um die Pflanzen kümmern muss.

Die main-Methode ist bereits vorgegeben. Sie versorgt drei Pflanzen, summiert das dabei verbrauchte Wasser auf und führt zum Schluss einen Probelauf für den Winter durch. Die Messwerte liefert die Klasse Sensor (siehe Reiter Sensor). Damit das Programm funktioniert, fehlen noch die folgenden Klassenmethoden, die Sie in der Klasse Irrigation schreiben sollen:

  • private static int waterAmount(int baseAmount, int season)

    Berechnet, wie viel Wasser (in ml) eine Pflanze benötigt. baseAmount ist die normale Wassermenge der Pflanze. Im Sommer braucht die Pflanze doppelt so viel, im Winter nur die Hälfte. In Frühling und Herbst bleibt es bei der normalen Menge. Die berechnete Menge wird zurückgegeben.

  • private static void water(String plant, int amount)

    Gießt die Pflanze, indem sie z.B. Kaktus wird mit 50 ml Wasser gegossen. auf der Konsole ausgibt.

  • private static void fertilize(String plant)

    Düngt die Pflanze, indem sie z.B. Kaktus wird geduengt. auf der Konsole ausgibt.

  • public static int plantCare(String plant, int baseAmount, int season)

    Versorgt eine Pflanze in der übergebenen Jahreszeit:

    • Lesen Sie mit Sensor.getMoisture die Bodenfeuchte der Pflanze aus und geben Sie diese aus.
    • Liegt die Bodenfeuchte unter 30 %, wird die Pflanze mit der von waterAmount berechneten Menge gegossen. Verwenden Sie dazu Ihre Methode water. Andernfalls wird ausgegeben, dass die Pflanze nicht gegossen werden muss.
    • Im Frühling und im Sommer wird die Pflanze zusätzlich mit fertilize gedüngt.
    • Die Methode gibt die verbrauchte Wassermenge zurück (0, falls nicht gegossen wurde).

  • public static int plantCare(String plant, int baseAmount)

    Eine überladene Variante von plantCare ohne Jahreszeit-Parameter. Sie versorgt die Pflanze in der aktuellen Jahreszeit, die Sie mit Sensor.getSeason() bestimmen. Schreiben Sie den Code dafür nicht noch einmal, sondern rufen Sie die erste Variante von plantCare auf und geben Sie deren Ergebnis zurück.

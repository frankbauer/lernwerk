Aufgabe

Der Sierpinski-Teppich ist ein Fraktal, das nach einer einfachen Regel entsteht: Man zerlegt ein Quadrat in 3 × 3 gleich große Teilquadrate und lässt das mittlere leer. Mit jedem der acht übrigen Teilquadrate verfährt man genauso, und so weiter, bis die Teilquadrate nur noch ein einzelnes Feld groß sind.

Implementieren Sie die Methode teppich(Leinwand leinwand, int zeile, int spalte, int groesse) rekursiv. Sie soll das Quadrat mit der linken oberen Ecke zeile / spalte und der Seitenlänge groesse zu einem Sierpinski-Teppich machen. Die Seitenlänge ist immer eine Potenz von 3 (1, 3, 9, 27, …).

  • Ist das Quadrat nur ein Feld groß, wird es mit leinwand.fuellen(zeile, spalte) gefüllt.
  • Andernfalls ruft sich die Methode für die acht äußeren Teilquadrate mit einem Drittel der Seitenlänge selbst auf. Mehrere rekursive Aufrufe in einem Methodenaufruf nennt man eine Kaskadenrekursion.

Die Farben zeigen, in welcher Reihenfolge die Felder gefüllt werden. Bei richtiger Lösung gibt das Programm Folgendes aus:

Gefuellte Felder: 512

Hinweis: Die linke obere Ecke des Teilquadrats in Zeile i und Spalte j (jeweils 0 bis 2) liegt bei zeile + i * teil / spalte + j * teil, wobei teil = groesse / 3 ist.

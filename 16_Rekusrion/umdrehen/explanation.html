Erklärung

Eine rekursive Methode besteht aus einem Abbruchfall und einem rekursiven Fall:

  • Abbruchfall: Ein leerer oder einbuchstabiger Text sieht umgedreht genauso aus. Er wird mit return text; direkt zurückgegeben. Diese Prüfung muss zuerst kommen, sonst würde text.charAt(0) bei einem leeren Text eine Exception auslösen, und die Rekursion würde nie enden.
  • Rekursiver Fall: Der Text wird zerlegt in den ersten Buchstaben und den Rest. Der Rest ist um einen Buchstaben kürzer und wird mit demselben Verfahren umgedreht. Danach wird der erste Buchstabe hinten angehängt: dreheUm("Beispiel") = dreheUm("eispiel") + 'B'.

Die Reihenfolge der drei Zeilen im rekursiven Fall ist teilweise frei. rest muss nur vor dem rekursiven Aufruf deklariert sein, und alle drei Zeilen müssen hinter dem if-Block und vor dem letzten return stehen.

Ablauf für "abc":

dreheUm("abc") = dreheUm("bc") + 'a'
               = (dreheUm("c") + 'b') + 'a'
               = ("c" + 'b') + 'a'
               = "cba"

Erklärung

Die größte der n Scheiben kann erst bewegt werden, wenn alle kleineren Scheiben weder über ihr noch auf dem Zielstab liegen. Sie müssen also alle auf dem Hilfsstab liegen. Daraus ergeben sich drei Schritte:

  1. die oberen n - 1 Scheiben von von nach hilf bringen (rekursiv, jetzt mit nach als Hilfsstab),
  2. die größte Scheibe von von nach nach bewegen,
  3. die n - 1 Scheiben von hilf nach nach bringen (rekursiv, jetzt mit von als Hilfsstab).

Der Abbruchfall ist n == 0: Ein Turm ohne Scheiben muss nicht bewegt werden. Da jeder Aufruf die Methode zweimal aufruft, handelt es sich um eine Kaskadenrekursion. Für die Anzahl der Züge gilt z(n) = 2 · z(n - 1) + 1 mit z(0) = 0, also z(n) = 2ⁿ - 1: 15 Züge für vier Scheiben, 1023 für zehn. Weniger Züge sind nicht möglich.

hanoi(3, 0, 2, 1)
├── hanoi(2, 0, 1, 2)
│   ├── hanoi(1, 0, 2, 1)   → Scheibe 1: 0 -> 2
│   ├── Scheibe 2: 0 -> 1
│   └── hanoi(1, 2, 1, 0)   → Scheibe 1: 2 -> 1
├── Scheibe 3: 0 -> 2
└── hanoi(2, 1, 2, 0)
    ├── hanoi(1, 1, 0, 2)   → Scheibe 1: 1 -> 0
    ├── Scheibe 2: 1 -> 2
    └── hanoi(1, 0, 2, 1)   → Scheibe 1: 0 -> 2

Weil die Stäbe mit 0, 1 und 2 nummeriert sind, ergibt sich der Hilfsstab übrigens immer aus den beiden anderen: hilf = 3 - von - nach. Man könnte den Parameter hilf also auch weglassen.

Aufgabe

Gegeben ist ein Graustufenbild als 2D-Feld von short-Werten (erster Index: Zeile, zweiter Index: Spalte) sowie ein Filterkernel als 3x3-Feld von double-Werten. Vervollständigen Sie die gegebenen Methoden der Klasse Fold:

  • Die Methode print soll den Inhalt eines 2D-Feldes zeilenweise auf der Konsole ausgeben.
  • Die Methode fold(int x, int y, short[][] image, double[][] kernel) soll eine diskrete Faltung für das Pixel an der Stelle (x, y) durchführen und den neuen Grauwert zurückgeben.

Das Programm soll folgende Ausgabe erzeugen:

50 30 20 10 40 
10 30 20 25 10 
40 30 50 20 40 
35 40 0 30 15 

--------------------------------------

0 0 0 0 0 
0 0 40 10 0 
0 5 35 15 0 
0 0 0 0 0 

--------------------------------------

Hinweis: Die Randpixel werden bei der Filterung ignoriert und bleiben im Ergebnis 0.

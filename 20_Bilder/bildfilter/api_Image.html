class Image

Ein Graustufenbild. Jeder Grauwert liegt zwischen 0 (schwarz) und 255 (weiß).

Konstruktor:

  • public Image(int[][] data)
Erstellt ein neues Bild aus den übergebenen Daten.

Attribute:

  • public final int width
Breite des Bildes in Pixeln.
  • public final int height
Höhe des Bildes in Pixeln.
  • public final int[][] data
Eigentlicher Bildinhalt. Der erste Index gibt die Spalte, der zweite die Zeile an.

Methoden:

  • public static Image load(String[] args)
Lädt das dem Programm übergebene Bild.
  • public void save()
Speichert das Bild und zeigt es nach Beendigung des Programms an. Werte außerhalb von 0 bis 255
werden dabei auf 0 bzw. 255 begrenzt.

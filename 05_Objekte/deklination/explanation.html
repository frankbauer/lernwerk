Erklärung

  • DateParser parser = new DateParser(args); - Erzeugt mit dem Konstruktor eine neue Instanz der Klasse DateParser und speichert die Referenz darauf in der Variablen parser. Als Parameter wird args übergeben, das Array mit den Programmargumenten der main-Methode. Darin steht das oben eingestellte Datum.
  • final int D = parser.getDayOfYear(); - Ruft die Instanzmethode getDayOfYear über die Referenz parser auf. Anders als bei einer Klassenmethode (z.B. Math.cos) steht vor dem Punkt also kein Klassenname, sondern eine Variable, die auf ein Objekt verweist.
  • System.out.println("Tag im Jahr: " + D); - Gibt den gelesenen Tag aus.
  • final double orbitalAngle = Math.toRadians((360.0 * (D + 10)) / 365.0); - Berechnet das Argument des Kosinus. Wichtig ist 360.0 statt 360: Sonst würde mit ganzen Zahlen gerechnet und die Division den Nachkommaanteil abschneiden. Da Math.cos den Winkel im Bogenmaß erwartet, wird das Ergebnis mit Math.toRadians umgerechnet.
  • final double declination = EARTH_TILT_RAD * Math.cos(orbitalAngle); - Die Neigung der Erdachse ist in der vorgegebenen Konstanten EARTH_TILT_RAD bereits im Bogenmaß gespeichert. Das Ergebnis ist daher ebenfalls im Bogenmaß.
  • System.out.println("Deklination: " + Math.toDegrees(declination)); - Rechnet die Deklination in Grad um und gibt sie aus.

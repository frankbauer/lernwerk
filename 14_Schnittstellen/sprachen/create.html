Nun soll die Sprache durch einen Benutzer festgelegt werden. Die hier gewählte Sprache wird Ihrem Programm als erster Parameter in args übergeben.

Sprache:

Erstellen Sie eine neue private Klassenmethode createGreeting(String), der die in args angegebene Sprache (de oder en) übergeben werden kann und die eine passende Greeting-Instanz zurückgibt. Wird eine ungültige Sprache angegeben, soll Englisch angenommen werden. Verwenden Sie die neue Methode in Ihrer main-Methode.

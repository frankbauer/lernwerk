Erklärung

  • Interface implementieren: Mit implements Greeting verpflichtet sich eine Klasse, alle Methoden des Interfaces bereitzustellen. greet muss dabei public sein, weil alle Methoden eines Interfaces öffentlich sind.
  • Nicht öffentlich: Deutsch und English stehen ohne public in derselben Datei wie die öffentliche Klasse Test. Pro Datei darf es nur eine öffentliche Klasse geben.
  • Referenz vom Typ des Interfaces: Greeting greeting = new Deutsch(); Von einem Interface selbst kann man kein Objekt erzeugen, eine Variable dieses Typs kann aber auf jedes Objekt einer Klasse verweisen, die das Interface implementiert. Nach greeting = new English(); ruft derselbe Aufruf greeting.greet() die englische Methode auf. Welche Methode ausgeführt wird, hängt vom Objekt ab, nicht vom Typ der Variable.
  • createGreeting: Der Rückgabetyp Greeting erlaubt es, je nach Sprache ein Deutsch- oder English-Objekt zurückzugeben. Zeichenketten vergleicht man mit equals, nicht mit ==. "de".equals(lang) funktioniert auch dann, wenn lang null ist.

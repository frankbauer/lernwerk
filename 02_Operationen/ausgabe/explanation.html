Erklärung

In der Beispiellösung steht unter jeder Zeile, was sie ausgibt. Mit Ausführen sehen Sie die Ausgabe des ganzen Programms.

Entscheidend ist, was zwischen den Klammern von System.out.println(...) steht und wie der Operator + ausgewertet wird.

  • System.out.println("GdI"); Text in Anführungszeichen wird genau so ausgegeben: GdI.
  • System.out.println(wert1); Ohne Anführungszeichen ist wert1 eine Variable. Ausgegeben wird ihr Wert: 12.
  • System.out.println("wert2"); Mit Anführungszeichen ist "wert2" nur ein Text. Der Name der Variablen spielt keine Rolle: wert2.
  • "wert2=" + wert1 und "Hallo" + wert1 Steht links vom + ein Text, wird der Wert rechts daran angehängt (verkettet): wert2=12 und Hallo12. Leerzeichen entstehen dabei nur, wenn sie im Text stehen.
  • "Welt " + wert2 Hier steht das Leerzeichen im Text, daher Welt 8.
  • wert1 + wert2 Sind beide Seiten Zahlen, wird addiert: 20.
  • "Summe: " + wert1 + wert2 Java wertet + von links nach rechts aus. Zuerst entsteht der Text "Summe: 12", daran wird dann 8 angehängt: Summe: 128.
  • "Summe: " + (wert1 + wert2) Die Klammern werden zuerst ausgewertet. 12 + 8 ergibt 20, erst dann wird verkettet: Summe: 20.

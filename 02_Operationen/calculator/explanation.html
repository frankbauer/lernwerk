Erklärung

Der vorgegebene Code verwendet die Variablen a und b, ohne sie zu deklarieren. In Java muss jede Variable deklariert werden, bevor sie verwendet wird.

  • int a = 8; Deklariert die Variable a und initialisiert sie direkt mit dem Wert 8. Der Wert muss 8 sein, da die Ausgabe a: 8 verlangt wird.
  • int b; Deklariert die Variable b ohne Wert. Den Wert 13 bekommt sie erst in der nächsten (vorgegebenen) Zeile b = 13;. Eine erneute Deklaration mit int b = 13; an dieser Stelle wäre falsch, weil b dann zweimal deklariert würde.
  • int c = a + b; ist bereits vorgegeben: c wird deklariert und bekommt die Summe 8 + 13 = 21.

Andere Lösungen sind ebenfalls möglich, z.B. int a = 8, b; in einer Zeile oder int b = 0;. Der Wert 0 wird in der nächsten Zeile ohnehin überschrieben.

Erklärung

Der Rahmen des Programms ist fest vorgegeben: Außen steht die Klasse, darin die main-Methode. Innerhalb der main-Methode gibt es dagegen mehrere richtige Reihenfolgen. Entscheidend ist nur, dass jede Variable deklariert ist und einen Wert hat, bevor sie verwendet wird.

  • public class MyOrder { und die letzte } umschließen das gesamte Programm.
  • public static void main(String[] args) { und die vorletzte } umschließen alle Anweisungen. Anweisungen außerhalb einer Methode sind in Java nicht erlaubt.
  • final int FIRST_FLOOR; muss vor FIRST_FLOOR = 0; stehen, und die Zuweisung wiederum vor jeder Verwendung von FIRST_FLOOR. Eine final-Variable darf genau einmal einen Wert bekommen.
  • House h = new House(); muss vor h.setTown(...) und vor h.addFloor(...) stehen.
  • Floor floor = new Floor(FIRST_FLOOR); deklariert floor. Erst danach darf floor verwendet oder mit floor = new Floor(FIRST_FLOOR+1); neu belegt werden.
  • Sinnvoll ist das Programm erst, wenn nach jedem new Floor(...) ein h.addFloor(floor); folgt. Sonst wird ein Stockwerk nie zum Haus hinzugefügt. Kompilieren würde es trotzdem.

Ob FIRST_FLOOR oder h zuerst angelegt wird, ist dagegen egal. Auch h.setTown(...) darf an beliebiger Stelle nach new House() stehen.

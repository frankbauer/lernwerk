Erklärung

  • int sum = 0; int count = 0; int last = 0; sind die Akkumulatoren. Sie werden vor der Schleife angelegt, weil sie nach der Schleife ausgegeben werden und weil sum schon in der Schleifenbedingung gebraucht wird.
  • int candidate = 2; ist die nächste Zahl, die geprüft wird. Sie wird in jedem Durchlauf um eins erhöht, egal ob sie eine Primzahl ist oder nicht.
  • while (sum + candidate < limit) Die Bedingung prüft vor dem Addieren, ob die Summe mit dem Kandidaten noch unter der Grenze bliebe. Würde man nur sum < limit prüfen, würde die letzte Primzahl noch addiert, obwohl sie die Grenze überschreitet.
  • Die Bedingung wird auch für Kandidaten geprüft, die keine Primzahl sind. Das ist in Ordnung: Wenn schon sum + candidate die Grenze erreicht, gilt das für die nächste (noch größere) Primzahl erst recht.
  • Nur wenn Prim.isPrim(candidate) wahr ist, werden alle drei Akkumulatoren aktualisiert.

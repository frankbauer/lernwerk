Beschreibung

Diese Klasse steuert den Spieler in der Welt mit der Kirsche. Alle Methoden sind Klassenmethoden (static) und werden über den Klassennamen aufgerufen, z.B. Controller.movePlayerLeft().

Methoden

  • public static void movePlayerLeft()
    Bewegt den Spieler einen Schritt nach links.
  • public static void movePlayerRight()
    Bewegt den Spieler einen Schritt nach rechts.
  • public static boolean isPlayerAtTarget()
    Prüft, ob der Spieler am Ziel (dem Startpunkt) angekommen ist.
  • public static boolean isPlayerLeftOfTarget()
    Prüft, ob der Spieler links vom Ziel steht.
  • public static boolean isPlayerRightOfTarget()
    Prüft, ob der Spieler rechts vom Ziel steht.

Die Schrittlänge nach links und nach rechts ist nicht gleich. Ein fest programmierter Rückweg funktioniert daher nicht zuverlässig.

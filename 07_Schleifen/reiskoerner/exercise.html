Aufgabe

Auf das erste Feld eines Schachbretts wird ein Reiskorn gelegt, auf jedes weitere Feld doppelt so viele wie auf das vorherige (1, 2, 4, 8, …). Berechnen Sie mit einer for-Schleife, wie viele Körner auf den ersten fields Feldern insgesamt liegen, und speichern Sie das Ergebnis in der Variablen total.

Felder:

Für 32 Felder soll das Programm Folgendes ausgeben:

Auf 32 Feldern liegen 4294967295 Reiskörner.

Tipp: Die Zahl ist zu groß für int. Verwenden Sie long.

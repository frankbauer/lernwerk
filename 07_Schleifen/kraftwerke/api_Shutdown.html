class Shutdown

Verwaltet die 13 Kraftwerke. Alle Methoden sind Klassenmethoden (static).

Methoden:

  • static int getNumberOfPlants()
Gibt die Anzahl der verfügbaren Kraftwerke zurück.
  • static int getMaxPowerProduced()
Gibt die von allen verfügbaren Kraftwerken produzierte Leistung (in MW) zurück.
  • static int getPowerNeeded(String[] args)
Gibt die benötigte Leistung (in MW) zurück. Übergeben Sie hier den args-Parameter der main-Methode.
  • static int getSinglePower(int idPowerPlant)
Gibt die Leistung eines Kraftwerks (in MW) zurück. Die IDs beginnen bei 0.
  • static void turnOff(int id0, int id1, int id2)
Schaltet die drei Kraftwerke mit den übergebenen IDs ab.

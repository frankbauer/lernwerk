Zählen Sie mit einem zweiten Akkumulator digits zusätzlich, wie viele Ziffern die Zahl hat. 
int digits = 0;
while (rest > 0) {
    sum += rest % 10;
    rest /= 10;
    digits++;
}
Geben Sie -4711 und 0 ein. Was passiert, und warum? Wie können Sie das Programm so ändern, dass auch negative Zahlen die Quersumme 13 liefern? Für negative Zahlen ist rest > 0 von Anfang an falsch. Die Schleife wird gar nicht ausgeführt, sum behält ihren Startwert 0. Abhilfe: 
int rest = Math.abs(number);
Berechnen Sie die Quersumme so lange immer wieder, bis nur noch eine Ziffer übrig bleibt (4711 → 13 → 4). Setzen Sie die bisherige Schleife in eine äußere Schleife. Wo muss sum jetzt auf 0 gesetzt werden? 
int rest = number;
while (rest >= 10) {
    int sum = 0;
    while (rest > 0) {
        sum += rest % 10;
        rest /= 10;
    }
    rest = sum;
}
System.out.println("Einstellige Quersumme: " + rest);

Aufgabe

In dieser Aufgabe programmieren Sie eine feste Spielsequenz. Verwenden Sie dazu die folgenden Klassenmethoden der Klasse FloatingWorld (eine vollständige Beschreibung finden Sie im Reiter FloatingWorld):

  • static void show() Zeigt die Welt an.
  • static Player addPlayer() Fügt einen Spieler hinzu.
  • static void movePlayerLeft(int idx) Bewegt den Spieler mit dem Index idx nach links.
  • static void movePlayerRight(int idx) Bewegt den Spieler mit dem Index idx nach rechts.
  • static void removePlayer(int idx) Löscht den Spieler mit dem Index idx.

Gehen Sie wie folgt vor:

  1. Fügen Sie zwei neue Spieler hinzu.
  2. Bewegen Sie den pinken Spieler nach rechts.
  3. Bewegen Sie den roten Spieler so oft nach rechts, bis er die Kirsche aufnimmt.
  4. Löschen Sie den pinken Spieler.
  5. Bewegen Sie den roten Spieler so oft nach links, bis er wieder an seiner Ausgangsposition steht.

Am Ende des Durchlaufs sollte der rote Spieler an seiner Ausgangsposition (weiß gestrichelter Umriss) mit der Kirsche über dem Kopf stehen.

Hinweis: Führen Sie Ihr Programm zwischendurch aus, um zu sehen, wie weit sich ein Spieler pro Aufruf bewegt.

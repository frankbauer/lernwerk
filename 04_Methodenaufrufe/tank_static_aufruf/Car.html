class Car

Beschreibung

Die Klasse Car dient zum Auslesen von Daten eines Pkw und zur Verwendung einiger im Fahrzeug integrierten Funktionen.

Konstanten

  • public static final int NORD
    Fahrt in Richtung Norden
  • public static final int NORDOST
    Fahrt in Richtung Nordosten
  • public static final int OST
    Fahrt in Richtung Osten
  • public static final int SUEDOST
    Fahrt in Richtung Südosten
  • public static final int SUED
    Fahrt in Richtung Süden
  • public static final int SUEDWEST
    Fahrt in Richtung Südwesten
  • public static final int WEST
    Fahrt in Richtung Westen
  • public static final int NORDWEST
    Fahrt in Richtung Nordwesten

Methoden

  • public static int getDirection()
    Gibt die Fahrtrichtung als Zahlenwert codiert zurück.
  • public static void printDirection(int direction)
    Gibt die übergebene Fahrtrichtung als Text aus.
  • public static float getConsumption()
    Gibt den aktuellen Verbrauch des Pkw in l/100km zurück.
  • public static float getFillLevel()
    Gibt die im Tank verbleibende Kraftstoffmenge in l zurück.
  • public static String getFillingStation(int direction, float range)
    Gibt eine Tankstelle in der übergebenen (oder einer ähnlichen) Richtung zurück, zu der die Entfernung kleiner als die übergebene Reichweite ist. Falls keine gültige Richtung übergeben wird, wird null zurückgegeben.
  • public static void startNavigation(String destination)
    Startet die Navigation zum übergebenen Ziel.

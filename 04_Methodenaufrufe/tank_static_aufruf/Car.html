Beschreibung

Die Klasse Car dient zum Auslesen von Daten eines Pkw und zur Verwendung einiger in diesem Fahrzeug integrierten Funktionen.

Methoden

  • public static int getDirection()
    Gibt die Fahrtrichtung als Zahlenwert codiert zurück.
  • public static float getConsumption()
    Gibt den aktuellen Verbrauch des Pkw in l/100km zurück.
  • public static float getFillLevel()
    Gibt die im Tank verbleibende Kraftstoffmenge in l zurück.
  • public static String getFillingStation(float direction, float range)
    Gibt eine Tankstelle in der übergebenen Richtung zurück, zu der die Entfernung kleiner als die übergebene Reichweite ist.
  • public static void startNavigation(String destination)
    Startet die Navigation zum übergebenen Ziel.

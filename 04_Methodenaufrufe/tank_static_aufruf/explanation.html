Erklärung

Dieses Programm zeigt, wie mit in einer API vorgegebenen Klassenmethoden gearbeitet werden kann. Klassenmethoden sind stets an dem Schlagwort static in der Methodensignatur in der API erkennbar.

  • Auslesen der Fahrtrichtung:

    Zum Auslesen der Fahrtrichtung wird die Klasssenmethode getDircetion der Klasse Car verwendet. Wie für Klassenmethoden üblich, wird diese auf dem Namen der Klasse aufgerufen, in der sie steht - hier Car. Die Methode erwartet laut API keine Parameter, weshalb die runden Klammern nach dem Methodennamen leer bleiben. Zurückgegeben wird ein int-Wert, der in der dafür angelegten Variablen direction gespeichert wird und die Fahrtrichtung codiert.

    int direction = Car.getDirection();
  • Ausgabe der Fahrtrichtung:

    Die Methode getDirection gibt lediglich einen Zahlenwert zurück, der die Richtung codiert. Das Programm selbst ist dazu ausgelegt mit diesem Zahlenwert zu arbeiten, aber für den menschlichen Benutzer ist anhand dessen nicht erkenntlich, um welche Richtung es sich handelt, weil die Zuordnung der Zahlen zu den Konstanten nicht in der API steht. Deshalb wird die Methode printDirection benötigt. Diese gibt die zum übergebenen Zahlenwert gehörige Richtung als Text aus - nicht zurück (Rückgabedatentyp void). Da die aktuelle Fahrtrichtung ausgegeben werden soll, welche zuvor in der Variable direction gespeichert wurde, wird direction als Parameter beim Methodenaufruf übergeben. Weil es sich um einen Methodenaufruf und keine Methodendeklaration handelt, steht in den runden Klammern vor direction kein Datentyp!

    Car.printDirection(direction);
  • Auslesen von Verbrauch und Füllstand:

    Wie bei der Fahrtrichtung gibt es auch zum Auslesen von Verbrauch und Füllstand jeweils eine Klassenmethode in der Klasse Car: getConsumption bzw. getFillLevel. Beide bekommen keinen Parameter übergeben (leere Klammern) und geben entsprechend der API einen float-Wert zurück. Um die zurückgegebenen Werte zu speichern, werden mit float consumption und float fillLevel zwei Variablen angelegt. Diesen wird mit "=" der jeweilige Methodenaufruf zugewiesen, was darin resultiert, dass sobald das Programm abläuft, die jeweilige Methode ausgeführt und der zurückgegebene Wert in die Variable links des "=" geschrieben wird. 

    float consumption = Car.getConsumption();
float fillLevel = Car.getFillLevel();
  • Berechnung der Reichweite:

    Mit der in der Angabe gegebenen Formel wird aus den zuvor ausgelesenen Werten für Verbrauch und Füllstand, die in den Variablen consumption und fillLevel gespeichert wurden, die Reichweite berechnet. Das Ergebnis wird in der float-Variable range gespeichert. Für range wurde der Datentyp float gewählt, da consumption und fillLevel vom Datentyp float sind und aus deren Division entsprechend ein float-Wert resultiert. Auch nach der Multiplikation mit dem int-Wert "100" ist das Ergebnis ein float-Wert, denn float ist gegenüber int dominant. Zudem erwartet die Methode getFillingStation einen float-Wert für die Reichweite. Würde man also statt float double für range verwenden, müsste man die Variable dann wieder zu float casten, wenn man sie an die Methode übergibt, da double größer ist als float. 

    float range = fillLevel/consumption*100;
  • Ausgabe von Verbrauch, Füllstand und Reichweite:

    Mittels System.out.println können Verbrauch, Füllstand und Reichweite als Text ausgegeben werden. Zur Verknüpfung von String-Elementen (z.B. "Verbrauch: ") und Variableninhalten (z.B. Variablenname consumption außerhalb von " ") in einem Ausgabe-Statement wird ein "+" zwischen den einzelnen Teilen gesetzt. 

    System.out.println("Verbrauch: " + consumption + " l/100km");
System.out.println("Fuellstand: " + fillLevel + " l");
System.out.println("verbleibende Reichweite: " + range + " km");
  • Bestimmen einer passenden Tankstelle:

    Um letzlich eine Tankstelle zu erhalten, die die gewünschten Kriterien erfüllt, wird die Methode getFillingStation aufgerufen. Diese erwartet als Übergabeparameter einen int-Parameter, der die Richtung codiert, und die berechnete Reichweite als float-Wert. Die Richtung haben wir zuvor in der Variable direction und die Reichweite in der Variable range abgespeichert. Deshalb können wir beim Methodenaufruf nun diese beiden Variablennamen in den runden Klammern übergeben.

    Achtung: Dass die Parameter in der Methodensignatur in der API auch direction und range heißen, also genau wie unsere angelegten Variabelen, ist reiner Zufall und nicht zwingend nötig. Theoretisch kann jede Variable vom passenden Datentyp oder auch Zahlenwerte übergeben werden. Auch hier gilt, es handelt sich um einen Methodenaufruf, weshalb in den runden Klammern keine Datentypen vor den Variablennamen mehr stehen!

    getFillingStation gibt einen String zurück, welcher in der Variablen fillingStation gespeichert wird. 

    String fillingStation = Car.getFillingStation(direction, range);
  • Starten der Navigation:

    Zu guter Letzt soll die Navigation zur Tankstelle gestartet werden. Dazu wird die Klassenmethode startNavigation verwendet. Dieser erwartet als Übergabeparameter einen String, der das Ziel der Navigation angibt. Im vorliegenden Fall wird die Variable fillingStation übergeben, die den Namen der gefundenen Tankstelle als String enthält. Hier wird nochmal deutlich, dass der Parametername in der API und der Name der beim Aufruf übergebenen Variable nicht übereinstimmen müssen (destination vs. fillingStation). Lediglich der Datentyp ist entscheidend. 

    Car.startNavigation(fillingStation);

Erklärung

In der Beispiellösung steht jedes Programmstück in einem eigenen Block { ... }. So dürfen die Variablennamen in mehreren Beispielen vorkommen. Beim Ausführen steht vor jeder Ausgabe der Buchstabe der Teilaufgabe, und hinter jeder print-Zeile steht als Kommentar, was sie ausgibt.

  • a) k >= n vergleicht 17 mit 48.3. Der long-Wert wird dazu in double umgewandelt. Das Ergebnis ist ein boolean: false.
  • b) Die Klammer wird zuerst ausgewertet: 4 + 88 ergibt 92. Danach wird an den Text angehängt: Erg : 92.
  • c) s + "= p" verkettet die Zahl -8 mit dem Text "= p". Das p steht in Anführungszeichen, also wird nicht die Variable ausgegeben: -8= p.
  • d) Ein long wird wie eine ganze Zahl ausgegeben, ohne L: 31.
  • e) "k" ist ein Text, nicht die Variable k: k.
  • f) -20 - z ist -20 - (-18) = -2, z - z ist 0. Da -2 == 0 falsch ist, wird der else-Zweig ausgeführt: been.
  • g) Zuerst wird 0 mit einem Leerzeichen ausgegeben. Dann gilt h = 0 / 8 * (3 - 0) = 0 * 3 = 0. Da print keinen Zeilenumbruch erzeugt, steht alles in einer Zeile: 0 0.
  • h) Von links nach rechts: u / u ist 1 (Zahl durch Zahl). Danach folgt ein Text, ab hier wird verkettet: 1 + "the" ergibt "1the", und "1the" + 13 ergibt 1the13.

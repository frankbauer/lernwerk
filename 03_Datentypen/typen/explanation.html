Erklärung

In der Beispiellösung steht hinter jeder Zeile als Kommentar der Datentyp. Mit Ausführen gibt Java die Typen selbst aus, in derselben Reihenfolge.

Für arithmetische Operatoren (+ - * / %) gelten zwei Regeln:

  1. byte, short und char werden vor dem Rechnen immer mindestens zu int.
  2. Danach bestimmt der größere der beiden Typen das Ergebnis, in der Reihenfolge int → long → float → double.
  • 3 + 4 ergibt int. 3.0f - 4.0 ergibt double, denn 4.0 ist ein double-Literal. 3.0f - 4 ergibt float. 5.0 / 4 ergibt double. 400L % 3 ergibt long.
  • 'A' ist ein char, "A" ein String. Einfache Anführungszeichen stehen für genau ein Zeichen, doppelte für eine Zeichenkette.
  • (byte)4 / (short)-200.0 Die Casts wirken nur auf den direkt folgenden Wert, hier also (byte)4 und (short)-200.0. Für die Division werden aber beide zu int: Das Ergebnis ist int, nicht short.
  • (byte)12 * 'A' und 'A' + 'B' Nach Regel 1 werden byte und char zu int, das Ergebnis ist int. 'A' + 'B' ergibt also die Zahl 131 und nicht den Text "AB".
  • Vergleiche (< > == ...) und logische Verknüpfungen (&& ||) ergeben immer boolean, egal welchen Typ die verglichenen Werte haben.
  • "Hallo" + 3 Ist einer der Operanden von + ein String, wird verkettet. Das Ergebnis ist ein String.

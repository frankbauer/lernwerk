Beschreibung

Diese Klasse verwaltet eine kleine Spielwelt mit einer Kirsche, in der Spieler hinzugefügt, bewegt und gelöscht werden können. Alle Methoden sind Klassenmethoden (static) und werden über den Klassennamen aufgerufen, z.B. FloatingWorld.show().

Methoden

  • public static void show()
    Zeigt die Welt mit der Kirsche an.
  • public static void addPlayer()
    Fügt einen neuen Spieler hinzu. Die Spieler werden in der Reihenfolge ihres Hinzufügens nummeriert, beginnend bei 0.
  • public static void movePlayerLeft(int playerID)
    Bewegt den Spieler mit dem Index playerID ein Stück nach links.
  • public static void movePlayerRight(int playerID)
    Bewegt den Spieler mit dem Index playerID ein Stück nach rechts.
  • public static void removePlayer(int playerID)
    Löscht den Spieler mit dem Index playerID. Alle Spieler mit einem größeren Index rücken um eine Position nach vorne.
